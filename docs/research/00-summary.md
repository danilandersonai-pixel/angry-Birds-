### 1.4. Способности (числа при V_MAX = 24)

Общее: одна активация на птицу, по `pointerdown` (вне HUD) или Space. Окно — от `launch + 0.05 с` до первого контакта; исключение — Bomb. Отметка на следе (точка 0.22). Касание в первые 0.05 с после выпуска игнорируется (дребезг пальца). Вспышка-кольцо r → 2.2r за 0.25 с. Скорости заданы как `K·V_MAX`.

| Птица | Поведение и числа |
|---|---|
| Red, Terence | способности нет. Тап — косметика: реплика и сведённые брови 0.6 с, без физики. Подсказка способности не показывается. Боевой клич AB2 — флаг P2 (02 §3.1) |
| Blues | исходная птица становится средней, создаются 2 новых тела r 0.252, m 0.60. Скорость поворачивается на ±0.14 рад (8°), модуль тот же. Боковые смещены на ±2.3·r = ±0.58 м поперёк скорости; если точка спавна внутри статики или блока — появляются в позиции средней. Визуальное вращение ±2 рад/с. ### 1.7. Урон: формула, пороги, пробитие

```text
pre-solve (на каждый контакт; мир заблокирован — ничего не создаём и не удаляем):
  если manifold.pointCount == 0 → выход (иначе getWorldManifold(reused) вернёт старые точки)
  vn = max по точкам манифолда (−(v_B − v_A)·n)              // > 0 — тела сближаются
  hits[contact].vn = max(hits[contact].vn, vn)               // ключ Contact живёт ровно один шаг (пул)
  ПРОБИТИЕ (если одна сторона — птица, другая — блок, TNT или свинья, и цель не dead):
    Jest = (1 + max(eA, eB)) · μ_red · vn,   μ_red = m1·m2/(m1 + m2)
    если mult·max(0, Jest − m_T·V0_T) ≥ hp_T:
       contact.setEnabled(false); пометить цель на удаление;
       bird.pendingVelScale = min(…, clamp(1 − 0.5·hp_T/dmgEst, 0.5, 0.9))   // применить после шага
post-solve (обычный и TOI-проход): hits[contact].J += Σ normalImpulses[i]   // числа копируем, массив переиспользуется
после world.step():
  для каждого hit с J > 0: первый контакт птицы; событие impact, если vn ≥ 1.5 и J ≥ 0.5 (не чаще раза в 80 мс на пару)
  если !damageEnabled или vn < V_GATE (0.5) → без урона
  для каждой стороны T (S — другая сторона); пропуск, если T — static, bird или dead:
     J0   = m_T · V0[T.material]           // свинья V0 = 3.0
     mult = S — птица ? BIRDS[kind].mult[T.material | 'pig' | 'tnt'] (пике Silver и рывок Chuck — свои)
          : S — static и T — свинья ? 0.7 : 1.0
     dmg  = mult · max(0, J − J0) → свинья в каске: каска берёт свою долю (§1.5)
     очки за урон: блок — damagePointsPerM2·S·applied/maxHp; свинья — damagePoints·applied/(maxHp + helmetHp); дробь копим
  hp ≤ 0 → в очередь удаления. Перед destroyBody будим тела из contactList удаляемого.
  TNT с hp ≤ 0 → взрыв (из взрыва — через 7 шагов = 0.12 с)
```

- `stars = won ? 1 + (score ≥ two) + (score ≥ three) : 0`; `stars.one = 0`.
- Черновик до калибровки (06 §8.2): `three = r1k(P + 0.45·B + 10 000·(N − nMin))`, `two = max(min(r1k(P + 0.30·B + 10 000·max(0, N − nMin − 1)), three − 5000), r1k(P + 2000))`. Здесь P — очки всех свиней с максимальным уроном, B — сумма «очков max» блоков.
- Калибровка (06 §8.3): K = 20 «типичных игроков» (σ угла 0.5°, σ силы 0.015, σ тапа 0.03 с) плюс жадный эксперт. `two = max(r1k(q40), r1k(P + 2000))`, `three = max(r1k(q80), two + 5000)`, оба ≤ `floor1k(best)`. Санити: доля 3★ у типичного игрока 10–35 %; диапазон three — эп. 1: 25–60 тыс., эп. 2: 35–80 тыс., эп. 3: 45–110 тыс.; при правке уровня пороги сдвигаются не больше чем на 15 %.
- Пример 1-1 (лаборатория 06, очки урона блоков там были 280 за м² для дерева): эксперт 36 040 → 25 000 / 35 000 (у оригинала 3★ = 32 000 [факт]). При 200 за м² сумма очков блоков 1-1 падает с 6580 до 5700, поэтому пороги пересчитываются калибратором на настоящем ядре.

### 1.12. Автомат уровня, тайминги и соответствие ядру

Ядро (`SessionState` из контракта) ведёт всё, что влияет на счёт и физику, и само держит тайминги 01. Поэтому бот в Node проходит уровень без GameScreen. GameScreen добавляет презентационные фазы: на интро и паузе он просто не вызывает `session.step()`.

### 1.13. Ввод (сводка 01 §4, 07 §16)

- `INTRO_*`, баннер, бонус → любое нажатие = `onSkip()`. `READY` + нажатие в радиусе захвата → прицел (pointer capture; второй палец игнорируется, его отпускание выстрела не делает). `FLYING` + левая кнопка или палец вне HUD → способность **на pointerdown**, дальше тот же палец может панорамировать. Остальное: сдвиг ≥ 8 px → пан; два пальца → щипок; правая и средняя кнопки мыши → только пан.
- HUD-кнопки делают `stopPropagation()` на pointerdown. Пауза из прицела вызывает `cancelAim()`. `pointercancel` в прицеле — отмена.
- Клавиши: Esc / P — пауза (в прицеле Esc — отмена); R — рестарт; Space — способность в полёте и пропуск в интро и баннерах; Enter; N — «Дальше»; L — «Уровни»; Z; F — полный экран; M / Shift+M — музыка / звуки; стрелки; `+`/`−`. Клавиатурный прицел (A) — P2.
- Canvas: `touch-action: none`; `preventDefault` для `contextmenu`, `gesturestart`, Ctrl+колесо (`passive: false`), Space и стрелок.

### 2.1. Обратно совместимые расширения контрактов (принято)

- `types.ts`, все поля необязательные:
  - `LevelDef.camera?: { castle?: { x, y, viewH }; aimViewH?: number }`;

  - `LevelDef.decor?: DecorDef[]`, `LevelDef.version?: 1`;
  - `PigDef.fragile?: true` и `id?` у блоков и свиней.
  
  Зеркальный треугольник — `angle = π/2` с переставленными w и h (записать в комментарий `BlockShape`).
- `events.ts`: необязательные `impact.size?: number` (√(w·h) блока — для высоты звука) и `pigsLaugh.pigs?: PigType[]`.
- `api.ts`: новых методов нет. Уточнения семантики:
  - `activateAbility()` в `flying` делает быстрый пропуск, если способности нет (§1.9);
  - бот активирует способность по `session.time`, хук `autoTapAt` не нужен;
  - `canGrab` возвращает false при `victoryPending`.
- `UI` — расширение из 07 §1.3: `showBanner`, `transition`, `toast`, `abilityHint`, `aimTutorial`, `setMotion`, колбэки `onSkip` и `onCameraHome`.
- `AudioEngine` — расширение из 05 §2.3: `playMusic(id, theme)`, `reward`, `scoreTick`, `setPaused`.

## 6. Что откалибровать первым на настоящем ядре

1. Приёмка ядра по §1.7: каждая строка калибровочной таблицы — юнит-тест с допуском ±10 %. Падения свиней с 3 / 3.4 / 4.5 / 6.7 м. Цепочка TNT при зазорах 2.0 и 2.5 м.
2. Множители против камня: Terence ×2.0 на 3-1, Silver в пике ×3.0 на 3-6. Если эксперт не укладывается в `nMin`, менять геометрию «сэндвичей» (балка 4×0.5 из камня имеет HP 118.8 и не ломается пике), а не `nMin`.
3. Чувство полёта: 2.3 с на 45° и «хлёсткие» прямые выстрелы 0.9–1.3 с. Если покажется «тяжело», допустим подъём V_MAX до 26.8 с масштабом x уровней ×(V/24)² (06 §2.2) — только целиком по кампании.
4. Хрупкость льда (ломается от падения с 2 м) и прочность king (0 % от деревянной доски с 4 м) — оставить, если бот и типичный игрок укладываются в целевые доли побед.
5. Авто aimViewH на 16:9, 4:3 и 21:9: Red не мельче 8 css px, сооружение в кадре на 1-1…1-5.
6. Звук на слух на iOS Safari и Android Chrome: шторм без щелчков; полька не совпадает фразами с темой серии (05 §1).
