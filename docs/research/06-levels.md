Что берём из него:

### 1.5. Как Rovio делает уровень [факт: интервью Arttu Mäki, PocketGamer; блог Rovio]

Порядок такой: **тема → набор птиц → блоки**. Типы блоков и их расстановку определяют выбранные птицы. Плохие уровни отсеиваются на плейтестах. Мы делаем так же: в карточке уровня (§10) сначала птицы и обучающий момент, потом конструкция.

### 1.6. Что дали исследования генерации уровней (Stephenson & Renz 2016–2017, генератор Iratus Aves) [факт: статьи и код]

- **Локальная опора.** Каждый блок опирается либо серединой, либо **обоими краями**. Края берутся с отступом внутрь `check_buffer = 0.05` ед. (≈ 0.11 м у нас). Подпорки под края ставятся с отступом `edge_buffer = 0.11` ед. (≈ 0.25 м = половина колонны). Это ровно наша П-рама: наружные грани колонн заподлицо с торцами балки. Режимы требований: 1 — середина или оба края, 2 — только оба края (по умолчанию), 3 — середина и края.
- **Глобальная устойчивость** проверяется отдельно: локально опёртая конструкция может упасть целиком. Квантитативная проверка с трением 0 не дала ложных «устойчиво» и пропустила 68.2 % кандидатов. Надёжный способ в «шумном» движке — симуляция и смещение блоков.
- **Робастность.** Конструкцию поворачивают на ±5°…±45° шагом 5°. Чем больше из 18 углов она выдерживает, тем лучше (`Z·(1 − r/18)` в фитнесе). Наш аналог — тест T2 с наклоном g.
- **Места для свиней** ранжируются по трём признакам:
  - защита `3·min(блоков слева, справа, сверху)`;
  - разброс — произведение расстояний до уже выбранных мест, вес 0.002;
  - «занятость»: место под краем платформы в пределах 0.8, бонус +1, сюда падают обломки.
- **Слабое место** — блок, в который можно попасть напрямую и чьё удаление задевает много объектов: +1 за блок, +10 за свинью, порог 15. Защита:
  - стопка блоков слева, закрывающая линию выстрела;
  - дополнительные подпорки;
  - замена материала на камень.
- **TNT** ставится по тем же принципам: рядом со свиньями и слабыми местами, вразброс, под краями платформ. Максимум 5 штук.
- **Птицы.** Число по формуле: `b = ⌈p/2⌉`, ещё +1, если структур `s ≥ ⌈p/2⌉`. Версия 2017 года подбирает число агентами: берётся минимум птиц, которым справился лучший из 8 ИИ-агентов. Типы птиц — по долям:
  - Red ∝ доля достижимых свиней;
  - Blues ∝ доля льда;
  - Chuck ∝ доля дерева;
  - Bomb ∝ доля камня;
  - Matilda ∝ доля свиней, закрытых платформами или рельефом.
- **Материалы:** базовые вероятности wood 0.4, ice 0.3, stone 0.3. Есть «траекторный» режим: блоки на пути выстрела к свинье делаются из одного материала (дерево или лёд), чтобы проложить «коридор» для нужной птицы.

> **Конфликт с ТЗ.** В задаче сооружения стоят на x ≈ 25–45 м. При финальной физике (03: `V 24`, `g 15`) за 34–38 м не дотягиваются Bomb, Matilda и Terence. Решение [рекомендация]: держать цели в x = 16…34. Если команда поднимет `V_MAX`, все x масштабируются на `(V/24)²`: при V = 26.8 зона станет 20…42, то есть почти как в ТЗ.

### 2.3. Разметка уровня (шаблон) [рекомендация]

| Зона x, м | Что там |
|---|---|
| −12 … −10 | левая граница `bounds.minX = −12` |
| −10 … +1.5 | ровная площадка рогатки: очередь до 8 птиц на `x = −1.6 − 1.1·i` (01 §2.1). Рельеф ровный, `y = hs` |

Рельеф (статические полигоны), хелперы в `prefabs.mjs`:
- `flatGround(x0, x1)` — земля, верх на y = 0.
- `plateau(x0, x1, top)` — плато или утёс.
- `hill(x0, x1, x2, x3, h)` — холм-трапеция с ровным верхом [x1, x2].

Из них собираются:
- **яма** — два `plateau` с промежутком;
- **пещера** — скала-стена плюс платформа-потолок;
- **террасы** — 2–3 `plateau` разной высоты.

Требования к рельефу:
- Ровные площадки под конструкции и свиней строго горизонтальны (§4.4).
- Наклонные участки — только «декор», скаты для шаров и откосы. Угол ≤ 35°, чтобы на них не застревали блоки.

## 4. Правила устойчивости (замер `exp1_rules.mjs`)

Методика:
1. Конструкция создаётся по авторским координатам.
2. **T0:** 90 шагов pre-settle без урона, затем меряем смещение от авторской позы и максимальную скорость.
3. Всё усыпляется, потом **T1:** будим всё, урон включён, 10 с.
4. **T2:** гравитация повёрнута на ±a° на 2 с, затем 6 с обычной.

Пороги:
- T0: смещение ≤ 0.05 м, скорость ≤ 1.0 м/с;
- T1: блоки ≤ 0.05 м и ≤ 2°, свиньи ≤ 0.10 м, ничего не разрушено, потеря HP ≤ 1 %;
- T2: блоки ≤ 0.25 м и ≤ 10° (круги не считаем), свинья не опустилась больше чем на 0.3 м, ничего не разрушено.

### 4.2. Статическая проверка опоры (lint, до симуляции)

Быстрая проверка в редакторе и в тесте L, до запуска физики. Обе ошибки черновиков из §7.5 (свинья на коньке крыши, блок на склоне и свинья внутри холма) ловятся уже здесь: опора не горизонтальна, есть перекрытие с рельефом.

```ts
// Опора блока: всё, что касается его нижней грани (зазор ≤ 0.02 м, перекрытие по x > 0.05 м).
// Сначала строим граф опор (DAG снизу вверх, как у Stephenson & Renz), затем для каждого блока:
function supportMargin(b: Block): number {
  const load = subtree(b);                      // b + всё, что на нём (рекурсивно, доли при нескольких опорах — поровну)
  const com = centroid(load);                   // Σ m_i·x_i / Σ m_i
  const [L, R] = supportSpan(b);                // [min x, max x] пересечений нижней грани b с верхними гранями опор
  return Math.min(com.x - L, R - com.x);        // < 0 — упадёт; < 0.10 — хрупко (предупреждение)
}
// Правила lint: margin ≥ 0.10 (иначе предупреждение, < 0 — ошибка); перекрытия многоугольников ≤ 0.02 (SAT);
// зазор снизу ≤ 0.02; свинья: опора горизонтальна (|угол| < 0.2°), свободно ≥ 0.7 м с обеих сторон или стенка в ≤ 0.3 м,
// иначе нужен fragile:true; круг: стопоры на ≤ 0.1 м с обеих сторон; динамических тел ≤ 120; вершин в полигоне рельефа ≤ 12 после разбиения.
```

### 4.3. Почему «встык», а не с зазором

У planck кожа `polygonRadius = 0.01` с каждой стороны, `linearSlop = 0.005`. Поэтому зазор покоя ≈ 15 мм (03 §2.1):
- поставить блоки впритык без inset — стопка «растёт» на 15 мм на стык;
- поставить с зазором 5 см — детали падают друг на друга, это удар на спавне.

Наш контракт:
- автор пишет визуальные размеры встык;
- ядро делает `Box(w/2 − 0.0075, h/2 − 0.0075)`, а у треугольников сдвигает рёбра внутрь на 0.0075 (масштаб к центру вписанной окружности);
- полигоны рельефа тоже сжимаются, круги — нет.

Измеренный результат: смещение после pre-settle — 6–8 мм у всех правильных конструкций.

## 5. Свиньи, слабые места, TNT

### 5.1. Где ставить свиней [рекомендация на основе Classic и Stephenson & Renz]

Квоты на уровень:

| Тип места | Доля свиней | Пример | Чем решается |
|---|---|---|---|
| «Открытая» — наверху, на балке, на краю | 25–40 % (минимум одна свинья, кроме боссов) | medium на крыше башни | любая птица, удар в верх или опрокидывание |
| «Внутри» — в П-раме, под крышей | 30–50 % | small внутри домика | пробить стену или колонну, обрушить перекрытие |
| «В бункере» — камень со всех сторон | 0–25 % (с эп. 1-8) | medium в каменном бункере | Bomb, TNT, яйцо Matilda, Terence, пике Silver |
| «Ловушка» — под тяжёлым, под краем платформы, над пропастью | 10–30 % | свинья под каменной балкой на деревянных ножках | косвенное убийство: падение, придавливание |
| «Тыл» — за стеной, за утёсом | 0–20 % (с Hal, 2-5) | свинья за каменной стеной высотой 6 м | Hal, навес Matilda |

Правила размещения:
- **Первый выстрел даёт результат.** Хотя бы одна свинья гибнет от «естественного» выстрела Red или новой птицы в ведущее слабое место.
- **Расстояние между свиньями** — ≥ `r1 + r2 + 0.3`. Разброс по x — ≥ 40 % ширины композиции (дисперсия по Stephenson).
- **Высота падения:** свинья гибнет от падения при `0.7·(m·v·(1+e) − 3m) ≥ HP`, где `v = √(2·15·H)`.
  - small и medium — с ≈ 3.4 м (HP пропорционален массе, поэтому высота одна);
  - large — с ≈ 4.5 м.
  - Ловушку-пропасть делайте глубиной ≥ 4 м (≥ 5 м для large). [оценка по формуле урона 03 §3.6; уточнить замером в ядре]
- **King в босс-уровнях:** 1–2 «удара» (HP 31). Ставим под каменную крышу. Две птицы с способностью против камня — в очереди последними.

### 5.2. Слабые места [рекомендация]

- У каждого сооружения 1–2 **намеренных** слабых места. Это блоки из дерева или льда, видимые с рогатки, шириной ≥ 1 м.
- Оценка «вес слабого места» (+1 за каждый задетый блок, +10 за свинью) у ведущего слабого места — **15–40**.
- Если вес > 40 и это не обучающий уровень, слабое место защищаем одним из способов Stephenson:
  - заслон слева (стопка 1×1);
  - доп. опора;
  - камень.
- Конвейер выдаёт карту весов слабых мест (ядро может строить граф опор по контактам после pre-settle). Дизайнер смотрит, совпало ли с замыслом.

Следствия для дизайна:
- **Цепочка TNT** срабатывает при шаге ≤ 2.5 м. Чтобы не было случайной цепочки — шаг ≥ 3.5 м.
- **Bomb против бункера.** Каменная стена бункера не защищает от взрыва: в модели нет окклюзии. Поэтому против Bomb бункер делаем «далёким»: свинья в ≥ 3.5 м от любой поверхности, куда легко попасть. Против Red бункер защищает.
- **TNT как «лёгкий путь».** TNT в 2–2.5 м от 2–3 свиней даёт альтернативное решение. Так задуман 1-9.

|---|---|---|---|
| **L** lint (без физики) | граф опор и `supportMargin` (§4.2), перекрытия SAT, свиньи и круги, досягаемость каждой свиньи огибающей хотя бы одной птицы уровня, лимит тел | ошибок 0. Предупреждения выводятся в отчёт | < 5 мс |

### 7.2. Бот-эксперт (жадный перебор с повтором с нуля)

```ts
// Детерминизм: состояние после k выстрелов = пересборка уровня с нуля + повтор k выстрелов (тот же порядок тел, dt, итерации).
// Снимки planck (Serializer) не используем: теряется warm-start контактов, повтор не совпадёт бит-в-бит.
function candidates(bird: BirdType) {
  const A = range(4, 72, 2), P = [0.7, 0.8, 0.9, 1.0];                         // 35 × 4 = 140 на Red
  const T = { red: [null], terence: [null], chuck: [0.45, 0.7, 0.95], blues: [0.5, 0.8], bomb: [null /* авто-фитиль */, 'impact+0.2'],
              matilda: [0.6, 0.9, 1.2], hal: [0.5, 0.8, 1.1], silver: [0.4, 0.6, 0.8] }[bird];  // время тапа, с от запуска
  return A.flatMap(a => P.flatMap(p => T.map(t => ({ a, p, t }))));
}
function solve(level: LevelDef) {
  const shots: Shot[] = [];
  for (;;) {
    const s = replay(level, shots);                                  // createSession + launch/step для каждого выстрела
    if (s.pigsLeft === 0 || s.birdsLeft === 0) return { solved: s.pigsLeft === 0, birds: shots.length, score: finalScore(s), shots };
    let best = null;
    for (const c of candidates(nextBird(s))) {
      const t = replay(level, shots); fire(t, c); runUntilTurnEnds(t); // ход = птица ушла + мир спокоен 0.5 с, таймауты 8/10 с (03 §3.8)
      const v = -t.pigsLeft * 1e6 + t.score;                         // сначала свиньи, потом очки
      if (!best || v > best.v) best = { v, c };
    }
    shots.push(best.c);
  }
}
```

- Ход в решателе **ждёт полного успокоения** (консервативно). В игре следующая птица заряжается раньше (01 §5.3), так что игроку не сложнее.
- Тап способности задаётся временем от запуска. В ядре нужен тестовый хук `activateAbilityAt(t)` или вызов `activateAbility()` из цикла `step()` по времени.
- Стоимость [замер]:
  - выстрел-симуляция — 9.6 мс (7 блоков) … 36 мс (обрушение на холме);
  - на птицу 140 / 280 / 420 симуляций (Red / Blues / Chuck);
  - уровень 1-1 — 1.3 с, 1-8 — 6.4 с, нерешённый черновик 1-5 — 30 с.
- В CI можно урезать сетку до шага угла 4° и 3 сил. Тогда это ×0.4 по времени.

### 7.3. «Типичный игрок» (адаптивный бот с шумом)

На каждой птице:
1. Выбирается лучший выстрел по грубой сетке: угол 4…73° шагом 3°, сила {0.75, 0.9, 1.0}, оценка без шума.
2. Выстрел исполняется **с шумом прицела**: `σ_угол = 0.5°`, `σ_сила = 0.015`, `σ_тап = 0.03 с`. Это ±0.35 м по точке падения.
3. Дальше бот продолжает из реального состояния.

K прогонов с разными seed (`mulberry32`) дают:
- **долю побед** — главная метрика сложности;
- **число птиц**;
- **распределение очков** — по нему считаются звёзды.

Наивный повтор последовательности эксперта с шумом (без адаптации) — плохая метрика. На 1-2 и 1-3 он даёт 33 % и 10 % побед, а адаптивный бот — 60 % и 60 % [замер].

## 8. Пороги звёзд

### 8.1. Семантика

- `stars = won ? 1 + (score ≥ two) + (score ≥ three) : 0` (01 §11.1), `stars.one = 0`.
- 3★ в Classic обычно требует оставить 1–2 птицы и сильно разрушить сооружение [факт, 01]. Наши очки дают ту же шкалу:
  - каждая сэкономленная птица — 10 000;
  - все свиньи — 5000·p;
  - блоки — 500 + урон.

### 8.2. Черновая формула (до бота), уточнение 01 §11.2

```ts
// p — свиней; N — птиц; nMin — по замыслу; B — Σ «очки max» блоков (таблица §1.2), P = 5000·p + Σ PIG_DMG_PTS
function draftStars(N: number, nMin: number, P: number, B: number) {
  const r1k = (x: number) => Math.round(x / 1000) * 1000;
  const three = r1k(P + 0.45 * B + 10000 * (N - nMin));
  const two = Math.min(r1k(P + 0.30 * B + 10000 * Math.max(0, N - nMin - 1)), three - 5000);
  return { one: 0, two: Math.max(two, r1k(P + 2000)), three };
}
```

Для 1-1: p = 2, P = 10 100, B = 4·780 + 2·1060 + 1340 = 6 580, N = 3, nMin = 1 → three = 33 000, two = 22 000. Это близко к калибровке (35 000 / 25 000) и к оригиналу (32 000).

### 8.3. Калибровка по ботам (финальные пороги)

```ts
function calibrateStars(level, K = 20) {
  const exp = solve(level);                                     // эксперт
  const runs = range(K).map(k => typicalPlayer(level, { seed: 1000 + k }));
  const wins = runs.filter(r => r.won).map(r => r.score);
  const best = Math.max(exp.score, ...wins);
  const P = 5000 * level.pigs.length;
  const r1k = (x) => Math.round(x / 1000) * 1000, f1k = (x) => Math.floor(x / 1000) * 1000;
  const hi = f1k(best);                                           // эксперт всегда может взять 3★
  let two   = Math.max(r1k(quantile(wins, 0.40)), r1k(P + 2000)); // 2★ ≈ выше 40 % побед, не ниже «все свиньи + немного разрушений»
  let three = Math.max(r1k(quantile(wins, 0.80)), two + 5000);    // 3★ ≈ лучшие 20 % побед, минимум +5000 к 2★
  if (three > hi) { three = hi; two = Math.min(two, three - 5000); }
  if (two < r1k(P + 2000)) flag('узкий диапазон очков: добавьте разрушаемых блоков или птицу');
  return { one: 0, two, three, typicalWin: wins.length / K };
}
```

Санити-проверки калибровки [рекомендация]:
- `three ≤ expertScore`. Эксперт всегда может получить 3★.
- Доля 3★ у типичного игрока — 10–35 %. Больше — уровень «щедрый», меньше — порог за гранью.
- `three` по эпизоду растёт монотонно в среднем (боссы — выше) в пределах **25–60 тыс. (эп. 1)**, **35–80 тыс. (эп. 2)**, **45–110 тыс. (эп. 3)**. Ориентир — 32–75 тыс. в Poached Eggs 1-x.
- При правке уровня пороги не должны «уехать» больше чем на 15 % без причины (регрессия, 01 §11.3).

## 9. Кривая сложности и прогрессия

### 9.1. Метрики по уровням сложности [рекомендация; калибровка по §7]

| d | Где | Доля побед типичного игрока | Запас птиц `N − n_expert` | Птиц N | Свиней | Блоков | Сооружений |
|---|---|---|---|---|---|---|---|
| 1–2 | обучение | ≥ 95 % | 2 | 3 | 1–3 | 6–12 | 1 |
| 3–4 | ввод механики | ≥ 85 % | 1–2 | 3–4 | 3–4 | 10–20 | 1–2 |

| 9–10 | босс | ≥ 40 % | 0–1 | 5–8 | 5–9 + босс | 40–80 | 3 |

Структура эпизода — «пила»:

- **практика**: 2 уровня;
- **поворот**: новинка в неожиданном применении;
- **проверка**: комбинация с прошлым.

Под утёсом слева на земле деревянный `hut` x = 21.
- Материалы: всё.
- Свиньи: 2 helmet, medium, 2 small.
- Птицы: Red, Chuck, Matilda, Silver, Bomb.
- Учит: высота рогатки меняет углы. Дальность Red с холма 3 м — ≈ 40.6 м.

**3-8 «Ледяной мост»** · d 8 · N 5 (nMin 4)
- Конструкция: утёсы `plateau(11, 17, 4)` и `plateau(28.5, 34, 4)`, пропасть 11.5 м. Мост — 3 ледяные балки 4×0.5: 16.75–20.75, 20.75–24.75, 24.75–28.75 (на утёсы по 0.25). Стыки лежат на 2 ледяных сваях 0.5×4 (столб из двух колонн) на x = 20.75 и 24.75, со дна y = 0. На мосту 2 ледяных домика span 2 и каменный шар в колыбели. На правом утёсе каменный `bunker` на x = 31 (верх 6 при огибающей 6.5).
- Материалы: лёд, камень.
- Свиньи: 2 medium на мосту, small в домиках ×2, large в бункере.
- Птицы: Blues, Hal, Chuck, Terence, Red.
- Учит: обрушить мост (падение 4 м + удар шаром) вместо пробивания каждой свиньи.

**3-9 «Склад на льду»** · d 9 · N 5 (nMin 4)
- Конструкция: каменная крепость из двух `bunker` (span 3) на x = 22 и 28. На крышах бункеров по деревянной `frame` span 3, между ними ледяной мост `longBeam` 5×0.5 на x = 25 (опирание по 1 м). 5 TNT: 2 в бункерах (6 м друг от друга — без случайной цепочки), 3 на 2-м этаже с шагом 2.0 (в рамах и на мосту).
- Материалы: камень, дерево, лёд, TNT ×5.
- Свиньи: 7 — 2 helmet, 2 medium, 3 small.
- Птицы: Bomb, Silver, Matilda, Chuck, Hal.
- Учит: управляемая цепочка, нужен правильный порядок.

**3-10 «Цитадель короля» (финал)** · d 10 · N 8 (nMin 6–7)
- Конструкция:
  - ледяная стена `stack` 4×1×1 на x = 16;
  - центр: `plateau(21, 27, 1)`, цитадель на x = 24 — 3 яруса: каменные `bunker` ×2, рамы из дерева и льда с 2 шарами в колыбелях, зала king на каменных опорах по 3 м с крышей из двух slab. Верх 10.5 при огибающей 11.8;
  - боковые башни на x = 19 и 30 (2 этажа, верх 5);
  - 3 TNT у основания цитадели.
- Материалы: всё. ≤ 80 блоков.
- Свиньи: king, mustache, 2 helmet, 2 medium, 2 small.
- Птицы: Red, Blues, Chuck, Bomb, Matilda, Hal, Terence, Silver.
- Учит: финал — каждая птица на «своей» цели. Типичный игрок побеждает в ≥ 40 %.

## 11. Чек-лист дизайнера (порядок работы)

1. Тема и обучающий момент → **набор и порядок птиц** (как у Rovio, §1.5) → `nMin`.
2. Разметка по §2.3: цели в x = 16…34, высоты под огибающей нужных птиц (§2.2).
3. Конструкции только из макросов §3. Свиньи по квотам §5.1. Слабые места по §5.2.
4. `npm run levels:lint` (L) → T0/T1/T2 → эксперт. Если эксперт не уложился в `nMin` — правим конструкцию, а не `nMin`.
5. Калибровка K = 20: доля побед типичного игрока против цели d (§9.1).
   - Не хватает побед из-за **числа** птиц (с +1 птицей доля растёт, как в 1-3) — добавить птицу.
   - Не хватает из-за **точности** (как в 1-2 и 1-8) — упростить геометрию или материал.
6. Звёзды из калибратора, `meta.calib` записан, хэш совпал. Визуальный проход: декор (`decor`), «castle»-камера, подсказка `hint` для вводных уровней.

## 12. Согласование с другими документами и открытые вопросы

| Вопрос | Здесь | Что сделать |
|---|---|---|
| Дальность | старт из ложа: Red 37.7 м (не 40.5) | 03 §2.2 считает от ANCHOR. Зону целей ставим 16…34. Если поднимут `V_MAX` — масштаб x на `(V/24)²` |
| 01 «сооружения 18–55 м» | 16…34 м | 01 §1.2 писалось при V 29 — поправить ссылкой на этот документ |
| Блок 1×1 = 0.85 м (01 §9.2) | сетка U = 0.5, квадрат 1×1 м | очки за урон считаются по площади, формула не меняется |
| `slingshot` в контракте (комментарий «~ (0, 2.4)») | ANCHOR = основание + (0, 2.7) по 01 §2.1 | поправить комментарий в `types.ts` при следующем изменении контракта |
| Зеркальный треугольник | `angle = π/2` + w↔h | отразить в комментарии к `BlockShape` |
| Хрупкие свиньи на колоннах | флаг `fragile` (расширение) | добавить в `PigDef` или хранить список id в `meta` |
| Тап по времени для решателя | нужен детерминированный хук | `GameSession.activateAbility()` вызывать из теста по `time`. Предлагаем `opts.autoTapAt` в `launch` для тестов |
| Падение свиней в пропасть | оценка по формуле: small и medium с 3.4 м, large с 4.5 м | замерить в ядре и при необходимости углубить ямы |
| Окклюзия взрыва | нет (стены бункера не экранируют) | осознанно: роль Bomb. Если добавят окклюзию (03 D: `occlusion` ×0.5 за тело) — пересчитать §5.3 |
| Hal и Silver в решателе | в лаборатории не реализованы | калибровать 2-5…3-10 только на настоящем ядре |
| King-зала | опоры по 3 м: квадрат 1×1 + колонна 0.5×2 | проверить T2 в ядре. Вертикальный longBeam 0.5×5 тоже можно, но стройность 2.5/0.25 = 10 > 8 — только со связями (балка сверху) |
