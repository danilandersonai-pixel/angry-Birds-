## 1. planck.js 1.5.1: что нужно знать (по исходникам `node_modules/planck/src`)

### 1.1. Версия и установка

- [замер] `npm install planck` в чистой папке поставил **1.4.2**, хотя `latest = 1.5.1` (релиз 2026‑10‑12). Явный `npm install planck@1.5.1` сработал. Вероятно, это политика реестра или прокси к свежим релизам. В проекте `"planck": "^1.5.1"`, в `node_modules` стоит 1.5.1. **Фиксируйте точную версию** (`"planck": "1.5.1"`) и проверяйте `npm ls planck` в CI.
- [факт] Что важного в 1.5.1 (CHANGELOG): `World.step()` больше не падает в TOI-солвере на нефинитных состояниях. Исправлены дублирующиеся contact id в манифолдах edge/chain‑vs‑polygon: из-за них warm-start импульсы росли без ограничения на зажатом теле (#315). Для рельефа из `Chain`/`Edge` версия ≥ 1.5.1 обязательна.
- [факт] `engines: node >= 24`. На Node 22 работает, это только предупреждение. ESM: `import { World, Box, Circle, Vec2, Settings, WorldManifold } from 'planck'`. **Не импортируйте `Math`**: пакет экспортирует `math as Math`, и он затенит глобальный `Math`.
- Типы: `Body`, `Contact`, `ContactImpulse`, `Fixture`, `BodyType = 'static' | 'kinematic' | 'dynamic'`, `RayCastInput {p1, p2, maxFraction}`, `RayCastOutput {normal, fraction}`, `AABBValue {lowerBound, upperBound}`.

### 1.2. World и Settings

```ts
const world = new World({ gravity: { x: 0, y: -15 } });  // остальное — по умолчанию
world.step(1 / 60, 10, 8);                                // итерации должны быть целыми, иначе берутся дефолты
```

`WorldDef`: значения по умолчанию [факт]:

| Поле | Default | Мы |
|---|---|---|
| `gravity` | (0, 0) | (0, −15) |
| `allowSleep` | true | true |
| `warmStarting` | true | true |
| `continuousPhysics` | true (TOI для bullet и против статики) | true |
| `subStepping` | false | false |
| `blockSolve` | true | true |
| `velocityIterations` / `positionIterations` | 8 / 3 | **10 / 8**, передаём в `step()` |

`Settings` (статические, менять до создания мира; мы оставляем как есть) [факт]:

| Константа | Значение | Что значит для нас |
|---|---|---|
| `linearSlop` | 0.005 м | допуск проникновения |
| `polygonRadius` | `2·linearSlop` = 0.01 м | «кожа» полигона. Полигоны касаются на расстоянии 0.02 м, покоятся с видимым зазором ≈ 15 мм |
| `velocityThreshold` | 1.0 м/с | при скорости сближения меньше 1 м/с restitution не применяется, отскока нет |
| `maxTranslation` | 2.0 м/шаг | потолок скорости 120 м/с при 60 Гц |
| `maxRotation` | 0.5π рад/шаг | потолок ω ≈ 94 рад/с |
| `maxLinearCorrection` | 0.2 м | максимум выталкивания за шаг (поэтому перекрытия разъезжаются плавно, без «выстрела») |
| `baumgarte` / `toiBaugarte` | 0.2 / 0.75 | |
| `timeToSleep` | 0.5 с | |
| `linearSleepTolerance` / `angularSleepTolerance` | 0.01 м/с / 2°/с (0.035 рад/с) | очень строгие пороги, см. §2.7 |
| `maxSubSteps` (TOI) | 8 | post-solve одного контакта может прийти несколько раз за шаг |

### 1.3. Тела и фикстуры

```ts
const b = world.createBody({
  type: 'dynamic', position: { x, y }, angle,          // angle в радианах
  bullet: false, linearDamping: 0, angularDamping: 0,
  allowSleep: true, awake: true, fixedRotation: false, gravityScale: 1, userData,
});
b.createFixture({ shape: new Box(w / 2 - INSET, h / 2 - INSET), density, friction, restitution });
b.createFixture({ shape: new Circle(r), density, friction, restitution });   // или new Circle({x,y}, r)
```

- [факт] `Box(halfWidth, halfHeight, center?, angle?)` — **полуразмеры**. `Polygon(vertices)` — до `maxPolygonVertices = 12` вершин, только выпуклый.
- [факт] Default `FixtureDef`: `friction 0.2`, `restitution 0`, **`density 0`**. Динамическое тело с нулевой плотностью получает массу 1 кг. Плотность задавайте всегда.
- [факт] Плотность — кг/м² (2D): `m = ρ·площадь`. Блок 0.5×2 из wood (ρ 0.7) весит 0.7 кг.
- [факт] `bullet` влияет только на динамику: включает CCD против других **динамических** тел. Против static/kinematic CCD работает всегда.
- [факт] `setLinearVelocity(v)` будит тело, если `|v| > 0`. `applyLinearImpulse(J, point, wake = true)` меняет `v += J/m`, `ω += (r × J)/I`. `setAwake(false)` **обнуляет** v, ω, силу и момент.
- [факт] Смена типа: `setType('dynamic' | 'static' | 'kinematic')`, есть шорткаты `setDynamic()` и т.п. Птицу проще **создавать в момент отпускания**: до запуска она — спрайт без тела.

### 1.4. Интегратор (важно для прицела)

[факт] `Solver.solveIsland`, полунеявный Эйлер:

```
v ← (v + h·(gravityScale·g + F/m)) · 1/(1 + h·linearDamping)
ω ← (ω + h·τ/I)                     · 1/(1 + h·angularDamping)
x ← x + h·v                          (с ограничением |h·v| ≤ maxTranslation)
```

Отсюда точное положение после `k` шагов без контактов и демпфинга [замер, `expB4_predict.mjs`]:

```ts
// совпадает с planck до 7.8e-14 м на 2.5 с полёта; непрерывная парабола ошибается на 0.313 м (= g·h·t/2)
x_k = x0 + k*h*vx
y_k = y0 + k*h*vy + h*h*g*k*(k+1)/2
```

### 1.5. События контактов

| Событие | Сигнатура | Когда | Можно |
|---|---|---|---|
| `begin-contact` | `(contact)` | AABB перекрылись и манифолд стал непустым | звук «касания», флаги |
| `end-contact` | `(contact)` | касание прекратилось или тело уничтожено | |
| `pre-solve` | `(contact, oldManifold)` | перед солвером, **каждый шаг**, только для бодрых тел, не для сенсоров. Вызывается и в TOI | `contact.setEnabled(false)` (пробитие), чтение скоростей сближения |
| `post-solve` | `(contact, impulse: ContactImpulse)` | после солвера, только для касающихся бодрых контактов. В TOI вызывается ещё раз | чтение `impulse.normalImpulses[]` / `tangentImpulses[]` |
| `remove-body` / `remove-fixture` / `remove-joint` | `(obj)` | при удалении | чистка ссылок |
| `add-body` / `add-fixture` / `add-joint` | `(obj)` | новое в 1.5.0 | |
| `pre-step` / `post-step` | `(dt)` | публикуются из `step()`, но **не типизированы** в `.d.ts` | в TS очищайте буферы сами перед `step()` |

Особенности [факт + замер]:

1. **Внутри любого колбэка мир заблокирован** (`world.isLocked() === true`). `destroyBody` **молча** возвращает `undefined` и ничего не делает. `createBody` возвращает `null` [замер, `expJ_destroy.mjs`]. Удаление и создание — в очередь, обработка после `step()`. Альтернатива — `world.queueUpdate(cb)`: выполнится сразу после текущего шага.
2. **`Contact` берётся из пула** (`contactPool`, общий для всех миров). Ссылку на контакт нельзя хранить дольше текущего шага: объект переиспользуют для другой пары. Как ключ `Map` — только внутри шага.
3. **`impulse.normalImpulses` — геттер, который каждый раз перезаполняет один и тот же массив.** Копируйте числа, а не массив.
4. Для bullet-птицы импульс удара приходит **целиком из TOI-солвера** [замер C1: `toiJ = maxStepJ`]. Обычный и TOI-вызовы для одного контакта суммируйте в пределах шага.
5. Спящие контакты не вызывают ни pre-, ни post-solve [замер C4: у заснувшей пирамиды `restMaxJ = 0`].
6. `contact.getWorldManifold(wm)` **не трогает** `wm`, если `pointCount == 0`. При переиспользовании объекта сначала проверяйте `contact.getManifold().pointCount`, иначе прочитаете устаревшие точки.

### 1.6. Запросы

- `world.queryAABB({lowerBound, upperBound}, fixture => boolean)` — вызывается для каждой **фикстуры** (proxy), поэтому тела дедуплицируйте через `Set`. Останавливается только на `return false`; `undefined` значит «продолжать». Рекомендуем явно `return true`.
- `world.rayCast(p1, p2, (fixture, point, normal, fraction) => number)`. Возврат: `0` — стоп, `fraction` — обрезать луч (ближайшее попадание), `1` — продолжить без обрезки, `-1` — игнорировать фикстуру. Фикстуры, внутри которых лежит `p1`, луч не видит.
- `fixture.rayCast(out, {p1, p2, maxFraction: 1}, childIndex)` — луч по одной фикстуре. Им считаем расстояние от центра взрыва до поверхности тела.

### 1.7. Смешивание материалов

[факт] `Contact.ts`: `friction = sqrt(fA·fB)`, `restitution = max(eA, eB)`. Следствия:
- **restitution земли «заражает» всех**. С `e_ground = 0.3` все блоки будут отскакивать. Земля и блоки `e ≤ 0.05`, упругими делаем только птиц (0.32) и свиней (0.15).
- Трение лёд–земля `sqrt(0.25·0.9) = 0.47`, лёд–лёд 0.25, дерево–дерево 0.7.
- При `vn < velocityThreshold = 1 м/с` отскока нет ни при каком `e`.

## 2. Эксперименты

Общая методика: создаём мир, ставим конструкцию, крутим `step(1/60, vi, pi)`, меряем. Хелперы — `lib.mjs`. Трекер импульсов — `impulse.mjs`, фрагмент ниже. Мини-движок с уроном, взрывами и settle — `game.mjs`. Финальные константы — `final_cfg.mjs`.

### 2.1. (a) Устойчивость башен и пирамид

Конструкции [замер, `expA_stability.mjs`]:
- `tower3` / `tower4` — этажи из двух колонн 0.5×2 (центры на ±1.75 м) и перекрытия 4×0.5 сверху;
- `pyramid5` — квадраты 1×1, ряды 5‑4‑3‑2‑1, горизонтальный зазор 0.02;
- `stack10` — столб из 10 квадратов 1×1 (стресс-тест).

Метрики за 10 с без воздействия: максимальное смещение любого тела, максимальный поворот, число «упавших» (смещение > 0.25 м или поворот > 10°), момент, когда заснули все.

**A0. Зазор покоя** (`expA0_gap.mjs`): box–земля 14.8–17.3 мм, box–box 14.6–19.2 мм, circle–земля 5.0–9.2 мм. Это следствие `polygonRadius = 0.01` (две кожи по 0.01 минус slop 0.005 ≈ 15 мм). При 45 px/м это 0.7 px, не видно, но **влияет на постановку уровня** (A3).

| tower4 (12 тел) | 9.7 / 3.35 | 8.8 / 2.48 | 5.1 / 1.27 | 3.3 / 0.93 |
| tower3 (9) | 5.1 / 1.28 | 4.6 / 1.02 | 2.2 / 0.72 | 1.3 / 0.60 |

Во всех 16 прогонах упавших 0, максимальный поворот ≤ 0.03°. Смещение — это миллиметровое «оседание» стопки на slop. **Вывод:** на 8/3 стоит всё, но 10/8 засыпает быстрее и почти не дороже (§2.9). Берём 10/8.

**A2. Трение и restitution в покое** (4 трения 0.2–1.0 × 3 значения restitution 0–0.3, 48 прогонов): результат **бит-в-бит одинаковый** внутри каждой конструкции. У симметричных стопок нет касательных сил, а без ударов нет и отскоков. Трение и упругость важны только при разрушении (A7, A8, §2.3).

**A3. Зазор при постановке** (tower4 / stack10, 10/8):

| Вертикальный зазор между деталями | −0.01 (перекрытие) | 0 (встык) | **0.015** | 0.05 | 0.2 |
|---|---|---|---|---|---|
| макс. смещение tower4, мм | 181 | 102 | **8.8** | 285 | 1482 |
| макс. смещение stack10, мм | 192 | 93 | **17.6** | 372 | 1904 |

При постановке «встык» стопка **растёт** на 15 мм на каждом стыке (кожа выталкивает, но плавно: `maxLinearCorrection`). При зазоре 5 см и больше детали падают друг на друга, а это удар на спавне.

**A6. Решение — сжатие коллизии (inset).** Уровень задаётся «встык» в визуальных размерах, а фикстура создаётся как `Box(w/2 − INSET, h/2 − INSET)`:

| INSET, м | 0 | 0.005 | **0.0075** | 0.01 |
|---|---|---|---|---|
| tower4, смещение 8/3 / 10/8, мм | 103.7 / 102.1 | 28.6 / 25.4 | **9.7 / 8.8** | 56.6 / 58.0 |

`INSET = 0.0075 = (2·polygonRadius − linearSlop)/2` даёт тот же результат, что идеальный зазор 0.015. Визуальный зазор становится 0. Для кругов inset не нужен: их собственная кожа 0.

### 2.3. (c) Импульсы в post-solve и калибровка урона

Трекер (фрагмент `impulse.mjs`, суть):

```js
const solver = world.m_solver;                     // помечаем вызовы из TOI-солвера
const orig = solver.solveWorldTOI.bind(solver);
solver.solveWorldTOI = (s) => { inTOI = true; try { orig(s); } finally { inTOI = false; } };
world.on('pre-solve', (c) => {                     // скорость сближения в точках манифолда (до солвера)
  const wm = c.getWorldManifold(null); if (!wm || !wm.pointCount) return;
  const A = c.getFixtureA().getBody(), B = c.getFixtureB().getBody();
  for (let i = 0; i < wm.pointCount; i++) {
    const p = wm.points[i], va = A.getLinearVelocityFromWorldPoint(p), vb = B.getLinearVelocityFromWorldPoint(p);
    vn = Math.max(vn, -((vb.x - va.x) * wm.normal.x + (vb.y - va.y) * wm.normal.y));   // > 0 — сближаются
  }
});
world.on('post-solve', (c, imp) => {               // J = сумма по точкам; копируем числа, массив переиспользуется
  let J = 0; for (const v of imp.normalImpulses) J += v;
  step[key(c)][inTOI ? 'toi' : 'reg'] += J;
});
```

Ни один глобальный порог по J не отделит «вес» от «удара». Скорость сближения из pre-solve отделяет идеально: в покое `vn = 0.00`, на спавне ≤ 0.20 м/с, у любого настоящего удара ≥ 1.2 м/с. Гейт `vn ≥ 0.5 м/с` убирает весь покой и при этом сохраняет 100% импульса ударов. Вес, приложенный после удара (vn снова 0), урона не наносит.

Вторая проблема — **масштаб по массе.** Тяжёлая свинья, падающая сама, получает импульс ∝ своей массе. С абсолютным порогом J и фиксированным HP большие свиньи «разбиваются» от падения с 1 м [замер K2: large pig 1.74 кг, HP 8 — гибнет с 1 м]. Решение — порог и HP, пропорциональные массе тела-цели (§3.6, проверка — §2.10).

### 2.4. (d) Взрыв Bomb

Реализация радиального импульса (фрагмент `expD_explosion.mjs`):

```js
export function explode(world, c, { R, J0, dvMax, applyAtSurface = true }) {
  const bodies = new Set();
  world.queryAABB({ lowerBound: { x: c.x - R, y: c.y - R }, upperBound: { x: c.x + R, y: c.y + R } },
    (fx) => { if (fx.getBody().isDynamic()) bodies.add(fx.getBody()); return true; });
  for (const b of bodies) {
    const com = b.getWorldCenter();
    let frac = 1, hit = false;                               // расстояние до ПОВЕРХНОСТИ: луч центр→COM по фикстурам тела
    for (let f = b.getFixtureList(); f; f = f.getNext()) {
      const out = {}; if (f.rayCast(out, { p1: c, p2: com, maxFraction: 1 }, 0) && out.fraction < frac) { frac = out.fraction; hit = true; }
    }
    const dCom = Math.hypot(com.x - c.x, com.y - c.y) || 1e-6;
    const d = hit ? frac * dCom : 0;                         // центр внутри тела → d = 0
    if (d > R) continue;
    const f = 1 - d / R;                                     // линейный спад
    const J = Math.min(J0 * f, b.getMass() * dvMax);         // кап Δv: лёгкие не «телепортируются»
    b.applyLinearImpulse({ x: (com.x - c.x) / dCom * J, y: (com.y - c.y) / dCom * J }, com, true);
  }
}
```

**D1. Сила и кап Δv** (tower4 wood ρ 0.7 + 2 свиньи 0.38 кг; взрыв сбоку у левой колонны или внутри, на первом этаже):

|---|---|---|---|
| R 4, J0 10 | 12.3 / 16.1 | 0/14 / 0.8 | 14/14 / 10.9 |
| R 4, J0 20 | 24.6 / 32.3 | 14/14 / 10.0 | 14/14 / 14.0 |
| R 4, J0 **40** | **49.3 / 64.6** | 14/14 / **98.5** | 14/14 / **54.6** |
| R 4, J0 30, dvMax 20 | 20.0 | 14/14 / 8.2 | 14/14 / 17.5 |
| R 3, J0 30, dvMax 20 | 20.0 | 14/14 / 10.1 | 14/14 / 17.5 |
| R 5, J0 30, dvMax 22 | 22.0 | 14/14 / 10.7 | 14/14 / 21.0 |

- Окклюзия (×0.5 за каждое тело на луче) почти ничего не меняет: сбоку 9.7 м вместо 8.2. В оригинале взрыв задевает и блоки «за» блоками [02], поэтому окклюзию **не делаем**.

### 3.6. Формула урона

```
Для каждого контакта c за шаг:
  J  = Σ по всем post-solve вызовам этого шага (обычный + TOI) Σ_i normalImpulse_i      [Н·с]
  vn = max по pre-solve вызовам шага и точкам манифолда (−(v_B − v_A)·n)                  [м/с]
  если !damageEnabled или vn < V_GATE (0.5 м/с) → пропуск
  для каждой стороны T контакта (S — другая сторона):
     если T неуязвим (static, ground, bird, уже dead) → пропуск
     J0   = m_T · V0[T.material]
     mult = S — птица   ? BIRD_MULT[S.kind][T.material]
          : S — static и T — свинья ? 0.7
          : 1.0
     T.hp −= mult · max(0, J − J0)
После шага: все с hp ≤ 0 → удалить (очередь), событие для очков, FX и звука; TNT → взрыв.
```

Почему именно так (всё замерено, §2.3):
- `J` с массой цели на «входе» и `V0` в пороге вместе ведут себя как «изменение скорости цели сверх V0», это интуитивно для падений. При этом тяжёлый камень бьёт сильнее лёгкой доски.
- Гейт `vn ≥ 0.5` убирает вес стопок (до 7.2 Н·с за шаг) и спавн (до 10.6 Н·с), сохраняя удары. 02 предлагал гейт 1.0 м/с: работают оба (покой 0.00, спавн ≤ 0.20, удары ≥ 1.2). Берём 0.5 — ловит медленное опрокидывание.
- Абсолютный `J_MIN = 0.25` из 02 больше не нужен: его роль играет `J0 = m·V0`.

Хук для звука и FX [рекомендация]: `intensity = clamp((J − 0.5)/15, 0, 1)`, событие только при `vn ≥ 1.5`. Громкость `0.2 + 0.8·intensity`. Пыль и щепки: `round(2 + 10·intensity)` частиц. Повтор для одной пары тел не чаще раза в 80 мс.

### 3.7. Взрывы

```
f  = 1 − d/R,  d — расстояние от центра взрыва до ПОВЕРХНОСТИ тела (fixture.rayCast центр→COM; центр внутри → d = 0)
J  = min(J0·f, m·dvMax)                       — вдоль (COM − c)/|COM − c|, приложить в COM
L  = −sign(COM.x − c.x) · spin · J · min(1, size/2)    — applyAngularImpulse (size = w для блока, 2r для круга)
dmg = D0 · f · blastMult[material]            — сразу в hp (без гейта), удаление после шага
```

| Источник | R, м | J0, Н·с | dvMax, м/с | D0 | spin | Прочее |
|---|---|---|---|---|---|---|
| Bomb | 3.5 | 30 | 20 | 100 | 0.15 | автоподрыв и тап — по 02 §3.4 |
| TNT | 3.0 | 25 | 18 | 80 | 0.15 | взрывается при hp ≤ 0; в цепочке задержка 0.12 с |
| яйцо Matilda [рекомендация] | 2.5 | 20 | 16 | 70 | 0.15 | заменяет `R 2.0, J0 7, D0 45` из 02: те числа под другую формулу |

Что даёт Bomb (D4): деревянная башня в 3 этажа теряет 7–8 из 9 блоков, гибнут 3 из 4 свиней уровня. В каменной башне в 2 этажа ломается 5 блоков из 6. Максимальная скорость обломков 20 м/с, разлёт 8–21 м (D1), ω ≤ 15 рад/с. Сама птица-бомба удаляется в момент взрыва, её тело в `explode` не попадает.

### 3.8. Покой (settle), «уход» птицы, сон

| Правило | Значение |
|---|---|
| Тихий шаг | каждое живое динамическое тело в границах мира спит **или** `|v| < 0.10 м/с` и `|ω| < 0.15 рад/с` |

```ts
// src/physics/PhysicsWorld.ts
import { World, Box, Circle, Vec2, WorldManifold, type Body, type Contact, type ContactImpulse, type RayCastOutput } from 'planck';
import { PHYS, MATERIALS, PIG_PHYS, BIRD_AFTER_IMPACT, SETTLE, GROUND, type MaterialId } from './constants';

export type EntityKind = 'block' | 'pig' | 'bird' | 'static';
export interface Entity {
  kind: EntityKind; body: Body; hp: number; maxHp: number; v0: number;
  size: number;                                   // w блока или 2r круга — для закрутки при взрыве
  material?: MaterialId | 'pig'; birdKind?: string; impacted?: boolean; dead?: boolean;
}
interface Hit { a: Entity; b: Entity; J: number; vn: number }
type BirdMult = (birdKind: string, target: MaterialId | 'pig') => number;   // таблица 02 §1.1

export class PhysicsWorld {
  readonly world = new World({ gravity: { x: 0, y: PHYS.GRAVITY } });
  damageEnabled = false;
  readonly entities = new Set<Entity>();
  private acc = 0;
  private hits = new Map<Contact, Hit>();         // живёт ровно один шаг: Contact из пула
  private readonly wm = new WorldManifold();      // переиспользуем, чтобы не мусорить в pre-solve
  private killQueue: Entity[] = [];
  onDestroyed?: (e: Entity) => void;              // очки, FX, звук, TNT → explode (после шага!)
  onImpact?: (a: Entity, b: Entity, J: number, vn: number) => void;

  constructor(private birdMult: BirdMult) {
    this.world.on('pre-solve', this.preSolve);
    this.world.on('post-solve', this.postSolve);
  }

  // ---------- создание ----------
  addStaticBox(x: number, y: number, w: number, h: number, angle = 0) {
    const body = this.world.createBody({ type: 'static', position: { x, y }, angle });
    body.createFixture({ shape: new Box(w / 2 - PHYS.INSET, h / 2 - PHYS.INSET), ...GROUND });
    return this.register({ kind: 'static', body, hp: Infinity, maxHp: Infinity, v0: 0, size: w });
  }
  addBlock(mat: MaterialId, x: number, y: number, w: number, h: number, angle = 0) {
    const m = MATERIALS[mat];
    const body = this.world.createBody({ type: 'dynamic', position: { x, y }, angle });
    body.createFixture({ shape: new Box(w / 2 - PHYS.INSET, h / 2 - PHYS.INSET), density: m.density, friction: m.friction, restitution: m.restitution });
    const hp = m.hpPerKg * m.density * w * h;     // HP по визуальной площади
    return this.register({ kind: 'block', body, hp, maxHp: hp, v0: m.v0, size: w, material: mat });
  }
  addPig(x: number, y: number, r: number, density: number, hpPerKg: number, friction = 0.6, restitution = 0.15) {
    const body = this.world.createBody({ type: 'dynamic', position: { x, y }, angularDamping: PIG_PHYS.angularDamping, linearDamping: PIG_PHYS.linearDamping });
    body.createFixture({ shape: new Circle(r), density, friction, restitution });
    const hp = hpPerKg * body.getMass();
    return this.register({ kind: 'pig', body, hp, maxHp: hp, v0: PIG_PHYS.v0, size: 2 * r, material: 'pig' });
  }
  launchBird(kind: string, x: number, y: number, r: number, density: number, friction: number, restitution: number, vx: number, vy: number) {
    const body = this.world.createBody({ type: 'dynamic', position: { x, y }, bullet: true, angularDamping: 0.3 });
    body.createFixture({ shape: new Circle(r), density, friction, restitution });
    body.setLinearVelocity({ x: vx, y: vy });
    this.damageEnabled = true;
    return this.register({ kind: 'bird', body, hp: Infinity, maxHp: Infinity, v0: 0, size: 2 * r, birdKind: kind, impacted: false });
  }
  private register(e: Entity) { e.body.setUserData(e); this.entities.add(e); return e; }

  presettle() {                                   // при загрузке уровня
    this.damageEnabled = false;
    for (let i = 0; i < PHYS.PRESETTLE_STEPS; i++) this.fixedStep();
    this.sleepAll();
  }
  sleepAll() { for (const e of this.entities) if (e.body.isDynamic()) e.body.setAwake(false); }

  // ---------- цикл ----------
  /** @returns alpha для интерполяции рендера между prev и текущей позой */
  update(frameDt: number): number {
    this.acc = Math.min(this.acc + frameDt, PHYS.DT * PHYS.MAX_STEPS_PER_FRAME);
    while (this.acc >= PHYS.DT) { this.fixedStep(); this.acc -= PHYS.DT; }
    return this.acc / PHYS.DT;
  }
  fixedStep() {
    this.hits.clear();                            // 'pre-step' не типизирован — чистим сами
    // перед шагом сохраните prevPos/prevAngle каждого тела для интерполяции (не показано)
    this.world.step(PHYS.DT, PHYS.VEL_ITERS, PHYS.POS_ITERS);
    this.resolveHits();
    this.cullOutOfBounds();
    this.flushKills();
  }

  // ---------- колбэки (НИЧЕГО не создаём и не удаляем) ----------
  private preSolve = (c: Contact) => {
    if (c.getManifold().pointCount === 0) return;          // иначе wm вернётся со старыми точками
    const wm = c.getWorldManifold(this.wm)!;
    const A = c.getFixtureA().getBody(), B = c.getFixtureB().getBody();
    let vn = 0;
    for (let i = 0; i < wm.pointCount; i++) {
      const p = wm.points[i];
      const va = A.getLinearVelocityFromWorldPoint(p), vb = B.getLinearVelocityFromWorldPoint(p);
      vn = Math.max(vn, -((vb.x - va.x) * wm.normal.x + (vb.y - va.y) * wm.normal.y));
    }
    const h = this.hits.get(c);
    if (h) h.vn = Math.max(h.vn, vn);
    else this.hits.set(c, { a: A.getUserData() as Entity, b: B.getUserData() as Entity, J: 0, vn });
    // здесь же — пробитие по контракту 02 §2.3 (contact.setEnabled(false) + очередь), если нужно
  };
  private postSolve = (c: Contact, imp: ContactImpulse) => {
    const ni = imp.normalImpulses;                          // переиспользуемый массив — только читаем
    let J = 0; for (let i = 0; i < ni.length; i++) J += ni[i];
    const h = this.hits.get(c);
    if (h) h.J += J;                                        // обычный + TOI вызовы суммируются
  };

  // ---------- урон ----------
  private resolveHits() {
    for (const h of this.hits.values()) {
      if (h.J <= 0) continue;
      for (const T of [h.a, h.b]) {
        if (T.kind === 'bird' && !T.impacted) {             // первый контакт птицы
          T.impacted = true;
          T.body.setLinearDamping(BIRD_AFTER_IMPACT.linearDamping);
          T.body.setAngularDamping(BIRD_AFTER_IMPACT.angularDamping);
        }
      }
      this.onImpact?.(h.a, h.b, h.J, h.vn);
      if (!this.damageEnabled || h.vn < PHYS.V_GATE) continue;
      this.damage(h.a, h.b, h.J);
      this.damage(h.b, h.a, h.J);
    }
  }
  private damage(T: Entity, S: Entity, J: number) {
    if (T.dead || T.kind === 'bird' || T.kind === 'static' || !T.material) return;
    const J0 = T.body.getMass() * T.v0;
    let mult = 1;
    if (S.kind === 'bird') mult = this.birdMult(S.birdKind!, T.material);
    else if (S.kind === 'static' && T.kind === 'pig') mult = PIG_PHYS.staticMult;
    this.applyDamage(T, mult * Math.max(0, J - J0));
  }
  applyDamage(T: Entity, dmg: number) {
    if (dmg <= 0 || T.dead) return;
    T.hp -= dmg;
    if (T.hp <= 0) { T.dead = true; this.killQueue.push(T); }
  }
  private flushKills() {
    // onDestroyed может взорвать TNT → новые смерти; обрабатываем до опустошения очереди
    while (this.killQueue.length) {
      const e = this.killQueue.shift()!;
      this.onDestroyed?.(e);                                // читает позицию ДО удаления
      this.world.destroyBody(e.body);                       // безопасно: мы вне step()
      this.entities.delete(e);
    }
  }
  private cullOutOfBounds() { /* y < KILL_Y или x вне bounds ± BOUNDS_MARGIN → dead + killQueue */ }

  // ---------- взрыв ----------
  explode(c: { x: number; y: number }, p: { R: number; J0: number; dvMax: number; D0: number; spin: number }, exclude?: Body) {
    const bodies = new Set<Body>();
    this.world.queryAABB({ lowerBound: { x: c.x - p.R, y: c.y - p.R }, upperBound: { x: c.x + p.R, y: c.y + p.R } },
      (fx) => { const b = fx.getBody(); if (b.isDynamic() && b !== exclude) bodies.add(b); return true; });
    for (const b of bodies) {
      const e = b.getUserData() as Entity;
      const com = b.getWorldCenter();
      const dx = com.x - c.x, dy = com.y - c.y, dCom = Math.hypot(dx, dy) || 1e-6;
      let frac = 1, hit = false;
      for (let f = b.getFixtureList(); f; f = f.getNext()) {
        const out: RayCastOutput = { fraction: 1, normal: Vec2.zero() };
        if (f.rayCast(out, { p1: c, p2: com, maxFraction: 1 }, 0) && out.fraction < frac) { frac = out.fraction; hit = true; }
      }
      const d = hit ? frac * dCom : 0;
      if (d > p.R) continue;
      const k = 1 - d / p.R;
      const J = Math.min(p.J0 * k, b.getMass() * p.dvMax);
      b.applyLinearImpulse({ x: (dx / dCom) * J, y: (dy / dCom) * J }, com, true);
      b.applyAngularImpulse(-Math.sign(dx || 1) * p.spin * J * Math.min(1, e.size / 2), true);
      if (e.material && e.kind !== 'bird') {
        const bm = e.material === 'pig' ? PIG_PHYS.blastMult : MATERIALS[e.material].blastMult;
        this.applyDamage(e, p.D0 * k * bm);
      }
    }
  }

  // ---------- покой ----------
  private quietSteps = 0;
  /** вызывать раз в шаг после первого удара; true — settle */
  settleTick(): boolean {
    let moving = false;
    for (const e of this.entities) {
      const b = e.body;
      if (!b.isDynamic() || !b.isAwake()) continue;
      if (b.getLinearVelocity().length() > SETTLE.V_LIN || Math.abs(b.getAngularVelocity()) > SETTLE.V_ANG) { moving = true; break; }
    }
    this.quietSteps = moving ? 0 : this.quietSteps + 1;
    return this.quietSteps >= SETTLE.HOLD_STEPS;
  }
}

// Прицел: точные позиции planck через k шагов (без контактов и демпфинга)
export function predictPath(x0: number, y0: number, vx: number, vy: number, steps: number, g = PHYS.GRAVITY, h = PHYS.DT) {
  const pts: { x: number; y: number }[] = [];
  for (let k = 1; k <= steps; k++) pts.push({ x: x0 + k * h * vx, y: y0 + k * h * vy + (h * h * g * k * (k + 1)) / 2 });
  return pts;
}
```

Замечания к коду:
- TNT в `onDestroyed` вызывает `explode`, а не создаёт тела. Это безопасно: `flushKills` работает вне шага. Задержку цепочки 0.12 с делайте таймером игрового цикла: TNT, «убитый» взрывом, кладите в отложенную очередь и взрывайте через 7 шагов.
- Массив `entities` при `explode` не меняется: удаляет только `flushKills`.
- Интерполяция: перед `world.step` сохраняйте `prev = {x, y, angle}` каждого тела. Рендер рисует `lerp(prev, cur, alpha)`, угол через кратчайшую дугу.

## 5. Подводные камни (с цифрами)

1. **Удаление и создание в колбэках.** `destroyBody` внутри `begin-contact`/`post-solve` молча возвращает `undefined`, `createBody` возвращает `null`. Только очередь после `step()` или `world.queueUpdate()` [замер].
2. **Хранение `Contact` и `normalImpulses`.** Контакты в пуле, массив импульсов перезаписывается при каждом обращении. Ключуйте по `Contact` только в пределах шага, копируйте числа [факт].
3. **Двойной post-solve.** Для bullet-контакта импульс приходит из TOI-прохода, возможны до 8 подшагов. Суммируйте за шаг, иначе урон посчитается дважды или потеряется [факт + замер C1].
4. **Урон от покоя и спавна.** Сырой J покоящейся башни до 7.2 Н·с за шаг, спавна до 10.6 Н·с. Это больше, чем падение свиньи с 3 м (4.2). Обязательны гейт `vn ≥ 0.5` из pre-solve, pre-settle и включение урона с первым выстрелом [замер C4/C6].
5. **Постановка «встык» без inset.** Стопка в 4 этажа растёт на 102 мм. С зазором 5 см падает на 285 мм (удар на спавне). Нужно `INSET = 0.0075` [замер A3/A6].
6. **Туннелирование.** Небуллет-осколок 0.5×0.25 проходит сквозь динамическую доску 0.1–0.25 м уже на 30 м/с, птица r 0.45 — на 60 м/с. Bullet для птиц, `dvMax ≤ 20` во взрывах, минимальная толщина 0.25 м [замер E1].
7. **Телепорт от взрыва.** J0 40 без капа даёт 49–65 м/с и разлёт до 98 м. Кап `m·dvMax`, dvMax 20 [замер D1].
8. **Взрыв без закрутки.** Импульс в точке на луче к COM не создаёт момента (ω = 0). Нужен явный `applyAngularImpulse` [замер D1].
9. **Вечное качение.** Нет трения качения: птица после посадки катится 220 м, свинья — 33–66 м. Демпфинг птицы после удара 1.5/4, свиньи — angularDamping 3 [замер F].
10. **Остров не засыпает.** Одна свинья, ползущая по уклону от долей градуса до 2° (0.03–0.34 м/с), держит бодрой всю башню больше 15 с. Settle по порогам + принудительный `setAwake(false)` [замер G1/F5].
11. **Упругость «заражает».** `restitution = max(eA, eB)`: упругая земля сделает упругими все блоки. Земля 0, блоки ≤ 0.05. Отскок ≈ `e²·h`: при e 0.3 и падении с 2 м это 0.2 м [факт + замер A8].
12. **Плотность по умолчанию 0** → у динамического тела масса 1 кг независимо от размера [факт].
13. **Непрерывная парабола в прицеле** ошибается на 0.31 м за 2.5 с. Берите дискретную формулу [замер B4].
14. **Нецелые итерации.** `step(dt, 10.5, 8)` молча сбрасывает итерации на дефолт [факт].
15. **`queryAABB` по фикстурам**, а не по телам. Дедуплицируйте через `Set`. Возврат `undefined` продолжает запрос, `false` останавливает [факт].
16. **`getWorldManifold(reused)` при `pointCount == 0`** возвращает объект со старыми точками. Сначала проверяйте `getManifold().pointCount` [факт].
17. **`import { Math } from 'planck'`** затеняет глобальный `Math` [факт].
18. **Версия.** Чистый `npm install planck` поставил 1.4.2 при `latest` 1.5.1. В 1.4.x нет фиксов TOI и edge/chain (#315). Пиньте 1.5.1 [замер].
19. **Отношение масс в стопке.** До 3.7 (stone на wood) стабильно, дрейф ≤ 24 мм. Избегайте стопок с отношением > 10 (stone 4×0.5 на ice 0.5×0.5): солвер Box2D начинает проседать [факт Box2D; у нас проверено до 3.7].
20. **Спираль смерти.** На слабом устройстве 200 тел — ≈ 8–9 мс на шаг. Без капа шагов за кадр FPS падает лавинообразно. Кап 4 шага, лимит 120 тел [замер I1].
