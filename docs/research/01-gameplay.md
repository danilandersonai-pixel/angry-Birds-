# 01 — Игровая механика и игровой цикл

> Цель документа: дать разработчику готовые правила, числа и псевдокод для рогатки, полёта, способностей, камеры, хода, условий победы и поражения, очков, звёзд и прогресса. Мир в метрах, ось Y вверх, шаг физики 1/60 с, planck.js 1.5.x.

## 1. Масштаб и базовые константы

### 1.1 Пересчёт оригинала в наш масштаб

[факт] Rhett Allain (Wired) разметил видео полёта: траектория — чистая парабола с постоянным ускорением, без сопротивления воздуха. При допущении `g = 9.8 м/с²` получилось: скорость запуска ≈ 23 м/с, рост Red ≈ 0.7 м, рогатка ≈ 5 м. Ускорение Chuck — до ≈ 30 м/с.

В оригинале ничего не измерено в метрах, «метры» выведены из допущения о g. Масштабно-независимы только величины в «птичьих» единицах (диаметр Red `D`):

| Величина | Оригинал (D = 0.7 м) | В единицах D | Наш масштаб (D = 0.9 м) |
|---|---|---|---|
| g | 9.8 м/с² | 14.0 D/с² | **12.6 м/с²** → берём 12.5 |
| v запуска max | 23 м/с | 32.9 D/с | **29.6 м/с** → берём 29 |
| Дальность v²/g (ровная земля) | 54 м | 77 D | 67 м |
| Время полёта на 45° | 3.3 с | — | 3.3–3.4 с |
| v Chuck после ускорения | ~30 м/с | 42.9 D/с | ~38 м/с (= 1.3 · V_MAX) |

**Вывод о «тяжести»:** при `g = 10` и сохранённой дальности полёт на 45° идёт 3.8 с вместо 3.3. Это на 12% «плавучее» оригинала, поэтому рекомендуем `G = 12.5`. Если документ по физике (02) зафиксирует `g = 10`, пересчитывайте `V_MAX = sqrt(RANGE_TARGET · g) ≈ 26 м/с` и масштабируйте остальные скорости из этого документа на `sqrt(g / 12.5)`.

### 1.2 Траектории при G = 12.5, V_MAX = 29 (старт с высоты ложа 2.7 м, посадка на y = 0)

Посчитано тем же интегратором, что в planck (полунеявный Эйлер, dt = 1/60):

| 40° | 68.5 | 3.08 | 16.4 |

**Следствия для дизайна уровней** [рекомендация]:

| Начальная угловая скорость | 0 | — |

## 2. Рогатка

### 2.1 Геометрия (координаты относительно основания рогатки `S = (sx, groundY)`)

| Точка | Смещение, м | Назначение |
|---|---|---|
| `ANCHOR` (точка покоя ложа) | (0.00, 2.70) | центр птицы в заряженной рогатке; центр окружности оттяжки |
| `PRONG_BACK` (задний рог, дальше от зрителя) | (−0.30, 2.95) | крепление задней резинки (рисуется за птицей) |
| `PRONG_FRONT` (передний рог) | (+0.28, 2.90) | крепление передней резинки (рисуется перед птицей) |
| Провис пустого ложа | ANCHOR + (0, −0.10) | когда птицы нет |
| Очередь птиц | x = sx − 1.6 − i·1.1, y = groundY + r_i | ожидающие птицы стоят на земле слева |

[рекомендация] Высоту рогов (≈2.9 м ≈ 3.2 D) согласовать с документом по визуалу.

### 2.2 Захват и оттягивание

- Захват: `pointerdown` в состоянии `READY` в радиусе `GRAB_RADIUS = max(1.0 м, 44 css px / ppm)` от центра птицы. Захват вне радиуса начинает панорамирование камеры.
- Смещение захвата: запоминаем `grabOffset = birdPos − pointerWorld`, чтобы птица не прыгала под палец.
- Позиция птицы: `raw = pointerWorld + grabOffset`, `delta = raw − ANCHOR`, `d = min(|delta|, R_MAX)`, `pos = ANCHOR + normalize(delta)·d`.
- Угол: любой (360°). Тянем вправо — выстрел влево (в Classic это работает). Ограничение одно: `pos.y ≥ groundY + r_bird + 0.02`. При упоре в землю точку проецируем на допустимую часть окружности, а не просто срезаем `y`, иначе сила упадёт.
- Поворот спрайта птицы во время прицеливания: `angle = atan2(−delta.y, −delta.x)`, сглаживание τ = 0.05 с [рекомендация].
- Указатель: `setPointerCapture`. Если указатель ушёл за пределы canvas, птица остаётся на окружности. `pointercancel`, `blur` и `visibilitychange → hidden` считаются отменой выстрела (см. 2.4).
- Второй палец во время `AIMING` игнорируется, пинч-зум недоступен.

### 2.3 Сила от натяжения

```ts
// Направление выстрела — от птицы к ANCHOR (резинка тянет обратно)
const dir = ANCHOR.sub(pos);            // |dir| = d
const d = dir.length();
const t = clamp(d / R_MAX, 0, 1);       // натяжение 0..1
const speed = V_MAX * t * bird.launchScale; // ЛИНЕЙНО (закон Гука: E = ½kd², v ∝ d)
const v0 = dir.normalize().mul(speed);
```

- [факт] В оригинале скорость запуска не зависит от угла. Будь рогатка честной пружиной, против гравитации шло бы слабее, а этого нет. Работу против g на участке разгона не учитываем.
- Птица стартует из точки оттяжки `pos`, а не из `ANCHOR`. Разгон по резинке не симулируется: скорость `v0` задаётся мгновенно. Визуально ложе «догоняет» птицу (см. 2.5).
- `launchScale` по птицам [рекомендация, в Classic визуально скорость одинакова; тяжёлым чуть меньше, чтобы «чувствовался вес»]:

| Птица | launchScale | Масса (ориентир для 02-physics) |
|---|---|---|
| Red | 1.00 | базовая |
| Blues (до разделения) | 1.00 | 0.6× |
| Chuck | 1.00 | 0.9× |
| Bomb | 0.95 | 1.6× |
| Matilda | 0.97 | 1.2× |
| Hal | 1.00 | 1.0× |
| Terence (Big Brother) | 0.88 | 4×, радиус 0.8 м |

### 2.4 Отмена выстрела

| Условие при отпускании | Результат |
|---|---|
| `d < R_CANCEL` (0.5 м ≈ 1.1 r) | отмена: ложе с птицей пружинит обратно в `ANCHOR` за 0.25 с (easeOutBack), звук «отпущенной резинки» тихий, птица не тратится, состояние `READY` |
| `pointercancel`, `blur`, вкладка скрыта, нажат `Esc` | отмена, как выше; при `Esc` после отмены — пауза |
| `d ≥ R_CANCEL` | выстрел (`LAUNCH`) |

[рекомендация] Ниже `R_CANCEL` резинки рисуются без натяжения, звук «скрипа» не играет. Так игрок понимает, что выстрела не будет.

### 2.5 Резинки и ложе

- Порядок отрисовки: задний рог → задняя резинка → птица → кожаное ложе → передняя резинка → передний рог.
- Каждая резинка — линия от рога к краю ложа. Края ложа: `pouchCenter ± perp(dirToAnchor)·0.38 м`. Ложе — дуга, охватывающая птицу сзади.
- Толщина: `w = lerp(0.17, 0.08, t)` м, где `t = d / R_MAX`. Цвет `#3B2414`, блик `#6A4528` шириной `0.3·w` [рекомендация; финальные цвета — в доке по визуалу].
- Звук натяжения: скрип при переходе через пороги `t` = 0.3, 0.6, 0.9 с повышением тона (`playbackRate = 0.85 + 0.5·t`). Синтез — в доке по звуку.
- После выпуска ложе привязано к птице, пока `dot(bird − ANCHOR, launchDir) < 0` (≈3–5 кадров). Дальше оно отцепляется и колеблется вокруг `ANCHOR` как затухающая пружина:

```ts
// pouch: {p: Vec2, v: Vec2}; на отцепке v = birdVel * 0.55
const OMEGA = 30;     // рад/с
const ZETA  = 0.18;   // затухание; до покоя ~0.4 с, перелёт ~0.35 м
a = (ANCHOR + SAG - p) * OMEGA*OMEGA - v * (2*ZETA*OMEGA);
v += a*dt; p += v*dt;
if (|p-ANCHOR-SAG| < 0.01 && |v| < 0.05) snap();
```

- Пустая рогатка до прилёта следующей птицы: ложе висит с провисом 0.10 м.

## 3. Запуск и полёт

### 3.1 Кадр выпуска (`LAUNCH`, длится 1 тик)

1. `body.setType('dynamic')`, `setPosition(pos)`, `setLinearVelocity(v0)`, `setAngularVelocity(0)`, `setBullet(true)`, `setAwake(true)`.
2. `birdsRemaining -= 1`, `shotIndex += 1`, `bird.launchTime = time`.
3. Предыдущий след гаснет за 0.2 с, начинается новый (см. 3.3).
4. События `bird:launch` (голос птицы + «вжух» резинки) и `sling:release`.
5. Переход в `FLYING`.

### 3.2 Ощущение полёта

- Без сопротивления воздуха, без ветра (в Classic ветра нет). Траектория строго параболическая, пока нет способности или удара.
- В полёте птица не вращается. Спрайт ориентирован по вектору скорости: `angle = atan2(vy, vx)` с ограничением ±35° и сглаживанием τ = 0.08 с [рекомендация, так выглядит в Classic]. После первого контакта ориентацию ведёт физика.
- Перья: при запуске 4–6 перьев цвета птицы; при каждом ударе с импульсом > порога — ещё 2–4 (подробнее в доке по эффектам).

### 3.3 След из «пуфов»

[факт/наблюдение] В Classic за птицей остаётся дорожка из белых точек, и она видна, пока игрок целится следующей птицей. Это главное средство прицеливания. В месте активации способности — крупный «пуф».

| Параметр | Значение [рекомендация] |
|---|---|
| Когда добавляем точки | от запуска до первого контакта птицы (после удара след не продолжается) |
| Шаг | по пройденному пути, каждые `0.45 м` (не по времени, чтобы плотность не зависела от скорости) |
| Размер | чередование: чётные `r = 0.11 м`, нечётные `r = 0.065 м` |
| Отметка способности | одна точка `r = 0.22 м` в позиции активации |
| После разделения Blues | у каждой из трёх птиц свой след, `r × 0.7` |
| Цвет | `#FFFFFF`, альфа 0.9, контур `rgba(0,0,0,0.18)` толщиной 0.015 м |
| Сколько следов хранить | 1: текущий плюс последний завершённый. Старый гаснет за 0.2 с при новом запуске |
| Лимит | 400 точек на след (кольцевой буфер) |
| Появление точки | масштаб 0 → 1 за 0.12 с (easeOutBack) |
| Сброс | при рестарте уровня |

### 3.4 Предиктивная траектория в серии

| Игра | Предпросмотр траектории |
|---|---|
| Angry Birds (2009), Seasons, Rio | Нет. Только след предыдущего выстрела [факт] |
| Classic и Friends + power-up **Sling Scope** (с 2012) | Красная линия траектории без ограничения длины, раз за уровень. Не учитывает порталы и предметы [факт] |
| Angry Birds Space (2012) | Встроенная пунктирная дуга начального участка, изгибается у гравитационных колодцев [факт] |
| Angry Birds 2 (2015–2020) | Постоянной полной траектории нет; в обучении — подсказка рукой [не подтверждено источниками] |

**Наше решение:**
- Режим по умолчанию — Classic: предпросмотра нет, только след.
- Настройка `aimAssist: 'off' | 'short' | 'full'`. `short` — пунктир на первые 0.5 с полёта, 12 точек, альфа 0.7 → 0.1. `full` — до первого пересечения со статикой или сооружением, при помощи `world.rayCast` по отрезкам.
- На уровнях 1-1…1-3 включаем `short` принудительно, как обучающую подсказку в духе Space и AB2.
- Для точности предпросмотр считается тем же интегратором, что planck (полунеявный Эйлер с демпфированием), а не аналитической параболой. Иначе к 3 с полёта расхождение около 0.3 м.

```ts
function predict(p0: Vec2, v0: Vec2, steps: number, g = G, damping = 0, dt = 1/60) {
  const pts: Vec2[] = []; let p = p0.clone(), v = v0.clone();
  for (let i = 0; i < steps; i++) {
    v.y -= g * dt;                 // гравитация
    v.mul(1 / (1 + dt * damping)); // как в planck
    p.add(v.clone().mul(dt));
    if (i % 3 === 0) pts.push(p.clone()); // точка каждые 3 тика = 0.05 с
  }
  return pts;
}
```

## 4. Способности (тап в полёте)

### 4.1 Окно активации

Общее правило: **одна активация на птицу**. Окно открывается через `ABILITY_MIN_DELAY = 0.05 с` (3 тика) после запуска и закрывается при первом контакте с любой нефантомной фикстурой (`begin-contact`, сенсоры не в счёт).

| Птица | Окно | Эффект (кратко; параметры — в доке по птицам) |
|---|---|---|
| Red | нет способности; тап — только крик (косметика) | — |
| Blues | до первого контакта | разделение на 3: центральная сохраняет `v`, боковые повёрнуты на ±0.14 рад (≈8°) с тем же модулем; радиус каждой 0.25 м |
| Chuck | до первого контакта | `v = normalize(v) · max(|v|, 1.3·V_MAX)` (≈38 м/с) [оценка по Allain]. Импульс массы не добавляет, только скорость |
| Bomb | **с запуска до взрыва**, в том числе после удара | взрыв по тапу. Авто-фитиль: через `2.5 с` после первого контакта, с мигающим красным, частота мигания 2 → 10 Гц [факт: «взрывается через несколько секунд после первого удара или по тапу»] |
| Matilda | до первого контакта | яйцо вниз `v = (0, −20)`; сама Matilda `v = (vx·0.9, +14)` и улетает вверх [рекомендация] |
| Hal | до первого контакта | бумеранг: разворот по горизонтали с дугой (подробнее в доке по птицам) |
| Terence | нет | — |

- Если способность уже использована или окно закрыто, тап в полёте ничего не делает. Исключение — быстрый пропуск, см. 5.2.
- Отметка на следе: точка 0.22 м в позиции птицы в кадре активации.
- В момент активации — событие `bird:ability`, звук способности, микротряска камеры (амплитуда 0.08 м, 0.12 с) для Bomb и Chuck.

### 4.2 Ввод и разведение жестов

```
pointerdown в FLYING:
  если bird.canActivate() → activate(), потребить событие (пан не начинать)
  иначе → кандидат на пан
pointermove > 8 css px от точки down → PAN (после активации тоже можно тащить камеру)
две точки касания → PINCH (сбрасывает пан)
клавиатура: Space / Enter = activate; R = рестарт; Esc / P = пауза; ←→↑↓ = пан 12 м/с; +/− = зум ×1.25
```

- Активация срабатывает **на `pointerdown`**, а не на `pointerup`: задержка в 100–200 мс между нажатием и эффектом убивает ощущение контроля.
- В тачскрин-режиме игнорировать `pointerdown`, если с выпуска прошло меньше 0.05 с: защита от «дребезга» отпущенного пальца.

## 5. Жизненный цикл птицы и переход хода

### 5.1 Уход птицы (`retire`)

Птица уходит (облачко перьев её цвета 0.35 с, тело удаляется), когда выполнено **любое** условие [рекомендация; в Classic птица исчезает, остановившись]:

| Условие | Порог |
|---|---|
| Покой после удара | `hadContact && |v| < 0.25 м/с && |ω| < 0.5 рад/с` непрерывно 0.4 с, при этом с первого контакта ≥ 1.0 с |
| Таймаут после удара | 6.0 с с первого контакта |
| Таймаут полёта | 12.0 с с запуска (птица улетела вверх или вдаль) |
| Выход за границы | `x < bounds.minX − 8`, `x > bounds.maxX + 8` или `y < groundMinY − 8` |
| Bomb взорвалась | сразу после взрыва (тело удаляется, облачка нет — его заменяет взрыв) |
| Blues | группа уходит, когда ушли все три (каждая по тем же правилам) |
| Matilda | условия выше для Matilda; яйцо — отдельный снаряд, удаляется при взрыве |

### 5.2 Быстрый пропуск [рекомендация, в духе темпа AB2]

Если способность израсходована или её нет, с первого контакта прошло ≥ 1.0 с, а игрок тапнул (не начиная пан), птица уходит сразу. Это экономит 2–5 с на выстреле, когда игрок уже видит результат.

### 5.3 Переход хода (не ждём полного успокоения мира)

После ухода птицы:
1. `LINGER`: камера задерживается на месте событий `min(0.6 с, до calm)`. Выход раньше 0.6 с возможен, если мир уже спокоен.
2. `CAMERA_RETURN`: возврат к виду рогатки, длительность `T = clamp(0.5 + dist/45, 0.6, 1.4) с`, easeInOutCubic. `dist` — путь центра камеры в метрах.
3. Если есть птицы — `BIRD_TO_SLING`: следующая птица прыгает в ложе по параболе высотой 1.2 м за 0.45 с, кричит при приземлении, ложе проседает на 0.12 м и пружинит. Затем `READY`.
4. Если птиц нет — `SETTLING` (ожидание итога, раздел 7).

Физика всё это время продолжает работать: очки за падающие блоки и свиней начисляются, пока игрок целится следующей птицей. Так в Classic: можно стрелять, пока сооружение ещё оседает.

## 6. Камера

### 6.1 Модель

- Состояние: `center: Vec2` (мир, м), `viewH: number` — видимая высота мира, м. Пикселей на метр: `ppm = canvasCssHeight / viewH`. Ширина вида: `viewW = viewH · aspect`.
- Ограничения:
  - `viewH ∈ [VIEW_H_MIN = 9 м, VIEW_H_MAX = min(fitLevelH, 42 м)]`, где `fitLevelH` — высота, при которой видна вся ширина уровня: `(bounds.maxX − bounds.minX) / aspect`;
  - по x: `center.x ∈ [bounds.minX + viewW/2, bounds.maxX − viewW/2]`; если `viewW` больше ширины уровня — центрировать;
  - низ кадра: `center.y − viewH/2 ≥ groundMinY − 1.5` (под землю не смотрим);
  - верх кадра: `center.y + viewH/2 ≤ bounds.maxY` (по умолчанию 40 м).
- **Прижим к земле** [рекомендация, как в Classic]: в автоматических режимах низ кадра держится на `groundY − 1.2 м`. Зум растёт вверх от земли, полоса земли всегда видна.

### 6.2 Вид рогатки («aim view»)

- `viewH = level.camera.aimViewH ?? 15 м` (Red ≈ 6% высоты кадра, ≈65 px на 1080p).
- Позиция: рогатка на 20% ширины от левого края, низ кадра на `groundY − 1.2`.
- Если игрок сменил зум в `READY` или `AIMING`, его `viewH` запоминается и восстанавливается при каждом возврате к рогатке в этом уровне. При рестарте зум сбрасывается к `aimViewH`.

### 6.3 Интро — облёт уровня

[наблюдение] Classic начинает уровень видом на свиное сооружение и плавно ведёт камеру к рогатке. AB2 стартует с общего плана и приближается к рогатке.

| Фаза | Время (первая попытка) | Время (повтор / рестарт) | Детали |
|---|---|---|---|
| `INTRO_HOLD` | 0.0–1.0 с | 0.0–0.3 с | камера в `level.camera.focus` (центроид свиней), `viewH = max(aimViewH, высота сооружения + 6)`; свиньи хрюкают |
| `INTRO_PAN` | 1.0–2.8 с | 0.3–1.1 с | позиция и `viewH` интерполируются к aim view, easeInOutSine. Для длинных уровней (> 60 м) можно увеличить до 2.3 с |
| `BIRD_TO_SLING` | 2.8–3.25 с | 1.1–1.55 с | первая птица прыгает в ложе |

- Пропуск: любой `pointerdown` или клавиша в `INTRO_*` → быстрый доезд за 0.3 с (easeOutCubic), затем `BIRD_TO_SLING`.
- Пока идёт интро, ввод рогатки и пан недоступны.

### 6.4 Следование за птицей (`FLYING`, после удара — до ухода)

```ts
// цель по x: птица + упреждение по скорости
const lookX = clamp(bird.vel.x * 0.35, -4, 6);
targetX = bird.pos.x + lookX;
// птица держится в горизонтальной полосе 25%..65% ширины вида
// зум: птица и земля в кадре, плюс 3 м запаса над птицей
const needH = (bird.pos.y + 3.0) - (groundY - 1.2);
targetViewH = clamp(Math.max(userViewH, needH), VIEW_H_MIN, VIEW_H_MAX);
targetY = (groundY - 1.2) + targetViewH / 2;     // прижим к земле
// критически демпфированное сглаживание (экспонента по dt, не зависит от FPS)
center.x += (targetX - center.x) * (1 - Math.exp(-dt / 0.18));
viewH   += (targetViewH - viewH) * (1 - Math.exp(-dt / 0.35));
center.y = (groundY - 1.2) + viewH / 2;
```

- Если птица выше `VIEW_H_MAX`, она временно уходит за верх кадра. Пока она там, показываем у верхней кромки маркер-стрелку с иконкой птицы и высотой.
- Blues после разделения: следим за центроидом трёх птиц.
- Matilda после яйца: следим за яйцом до взрыва, потом за Matilda.
- Ручное управление: если в `FLYING` игрок начал пан или пинч, автоследование отключается до конца хода (`userOverride = true`). Возврат к рогатке всё равно происходит автоматически.
- Тряска от взрывов и сильных ударов: смещение `A · noise(t·25)`, `A = min(0.35, impulse / 400) м`, затухание 0.3 с. Ограничений камеры тряска не нарушает.

### 6.5 Ручной пан и зум

| Жест | Поведение |
|---|---|
| Пан пальцем или мышью (вне птицы) | мир движется за указателем 1:1. После отпускания — инерция: `v *= exp(−dt/0.25)`, стоп при `|v| < 0.2 м/с`. Скорость инерции — среднее за последние 80 мс движения |
| Колесо мыши | `viewH *= exp(deltaY · 0.0015)` (один щелчок ≈ ×1.16). Точка мира под курсором остаётся под курсором |
| Пинч | `viewH = viewH0 · (dist0 / dist)`, якорь — середина двух пальцев. Одновременно с пинчем — пан по движению середины |
| `Z` / двойной тап по пустому месту | переключение между общим планом (fit level) и видом рогатки, 0.5 с [рекомендация] |
| Где доступно | `READY`, `AIMING` (только колесо), `FLYING`, `LINGER`, `SETTLING`, `VICTORY_DELAY`. Нет в `INTRO`, `BONUS_COUNT`, `RESULTS` |

Якорный зум:

```ts
function zoomAt(screenPt, newViewH) {
  const before = screenToWorld(screenPt);
  viewH = clamp(newViewH, VIEW_H_MIN, VIEW_H_MAX);
  const after = screenToWorld(screenPt);
  center.add(before.sub(after));
  clampCamera();
}
```

## 7. Определение успокоения сцены (settle)

Сон тел planck (`linearSleepTolerance 0.01 м/с`, `angularSleepTolerance 2°/с`, `timeToSleep 0.5 с`) — слишком строгий критерий: стопки дрожат и засыпают по 3–6 с. Поэтому считаем свой «calm» и всегда ставим таймаут.

```ts
const CALM_V = 0.10;      // м/с
const CALM_W = 0.15;      // рад/с
const CALM_HOLD = 0.5;    // с непрерывного покоя
function isWorldCalm(world): boolean {
  for (let b = world.getBodyList(); b; b = b.getNext()) {
    if (!b.isDynamic() || !b.isAwake()) continue;
    if (b.getUserData()?.ignoreForSettle) continue;     // частицы-обломки, перья
    if (b.getLinearVelocity().length() > CALM_V) return false;
    if (Math.abs(b.getAngularVelocity()) > CALM_W) return false;
  }
  return !pendingExplosions && !activeFuses && !projectilesInFlight;
}
// в fixed-update:
calmTimer = isWorldCalm(world) ? calmTimer + dt : 0;
const settled = calmTimer >= CALM_HOLD;
```

| Контекст | Ожидание calm | Таймаут |
|---|---|---|
| `LINGER` (перед возвратом камеры) | не обязательно | 0.6 с |
| `SETTLING` (птиц нет, ждём итог) | `CALM_HOLD 0.6 с` | 7.0 с от входа |
| `VICTORY_DELAY` | `CALM_HOLD 0.4 с`, минимум 1.2 с | 3.5 с от смерти последней свиньи |

- Дополнительно не спокойно, пока: тикает фитиль Bomb или TNT, есть отложенные взрывы, летит яйцо Matilda.
- Тела за границами `bounds ± 8` уничтожаются и в расчёте не участвуют. Свинья, улетевшая за границы, считается убитой и даёт полные очки.

## 8. Победа и поражение

| Условие | Проверка | Переход |
|---|---|---|
| **Победа** | `pigsAlive === 0` — в любом состоянии из `READY, AIMING, LAUNCH, FLYING, LINGER, CAMERA_RETURN, BIRD_TO_SLING, SETTLING` | `VICTORY_DELAY` |
| **Поражение** | `birdsRemaining === 0 && activeBird == null && pigsAlive > 0 && (settled || t ≥ 7 с)` в `SETTLING` | `LOST_BANNER` |

Крайние случаи:
- Последняя свинья умерла, пока птица ещё летит. Победа, бонус за эту птицу не начисляется. Её очки за урон продолжают идти, пока не закончится `VICTORY_DELAY`.
- Последняя свинья умерла, пока игрок целится (`AIMING`). [факт: в Classic после смерти последней свиньи есть несколько секунд, когда можно выпустить ещё птицу.] Решение: дать доиграть начатое прицеливание. Выстрел засчитывается, бонус за эту птицу теряется. Новый захват в `READY` во время `VICTORY_DELAY` запрещён [рекомендация: иначе выгодная, но неочевидная эксплуатация «стрелять ради урона > 10 000»].
- Свиньи умерли от доосыпания после последней птицы (`SETTLING`). Победа, бонус 0.
- Птица застряла на сооружении и не успокаивается. Её уход по таймауту 6 с из раздела 5.1 гарантирует, что ход завершится.
- Рестарт или выход во время `VICTORY_DELAY` и `BONUS_COUNT` не сохраняют результат: рекорд пишется только при входе в `RESULTS`.

### 9.2 Формулы урона

```ts
// HP задаётся документом 02-physics; очки за урон пропорциональны доле снятого HP
const DMG_POINTS_PER_M2 = { glass: 140, wood: 280, stone: 420 }; // 1×1 = 0.85×0.85 м = 0.7225 м² → ~100/200/300
function onBlockDamage(block, dmgHp) {
  const applied = Math.min(dmgHp, block.hp);          // не больше остатка
  block.hp -= applied;
  const ptsMax = DMG_POINTS_PER_M2[block.material] * block.area;
  block.pendingPts += ptsMax * (applied / block.maxHp);
  addScore(Math.round(block.pendingPts)); block.pendingPts %= 1;  // дробь копим
  if (block.hp <= 0) destroyBlock(block); // +500, всплывающее число
}
const PIG_DMG_POINTS = { small: 50, medium: 100, large: 200, helmet: 150, mustache: 300, king: 1000 };
```

- Урон начисляется молча: цифра на счётчике HUD растёт, всплывающего числа нет. Всплывающие числа — только у разрушенного блока (500 + несписанный остаток урона) и у свиньи (5000).
- Объединение всплывающих чисел [рекомендация, против «каши»]: разрушения в радиусе 1.2 м за 0.25 с складываются в одно число, позиция — центроид.

### 9.3 Всплывающие числа

| Объект | Цвет текста | Обводка |
|---|---|---|
| Свинья | `#8BD62E` | `#1E4A0B` |
| Дерево | `#F2A541` | `#5A2E0C` |
| Стекло / лёд | `#9FE3FF` | `#1D4E6B` |
| Камень | `#D7D7D7` | `#3A3A3A` |
| Бонус птицы | цвет птицы: Red `#E0302A`, Blues `#4BA7E8`, Chuck `#FFD21F`, Bomb `#3A3A3A` (обводка `#FFFFFF`), Matilda `#F4F4F4`, Hal `#46A83A`, Terence `#B81E22` | `#000000`, альфа 0.6 |

- Анимация: появление scale 0.4 → 1.15 → 1.0 за 0.18 с; подъём на 1.4 м за 0.9 с (easeOutQuad); с 0.6 с — альфа 1 → 0.

### 9.4 Счётчик HUD

- Справа сверху: `Score` и под ним `Best` (рекорд уровня). Формат `toLocaleString('ru-RU')` (12 340).
- Плавный счёт: `shown += (target − shown) · (1 − exp(−dt/0.12))`, округление вниз. При `target − shown < 1` — приравнять.
- Пульс при начислении ≥ 5000: scale 1 → 1.12 → 1 за 0.2 с.

## 10. Бонус неиспользованных птиц (анимация)

Таймлайн после `VICTORY_DELAY`:

| t, с | Событие |
|---|---|
| 0.00 | баннер «УРОВЕНЬ ПРОЙДЕН!» влетает: scale 0 → 1.1 → 1.0 за 0.35 с; держится 1.2 с; фанфара |
| 0.00 | очки за физику замораживаются (`scoringLocked = true`); симуляция продолжает идти визуально |
| 0.40 | камера едет к рогатке и очереди: 0.8 с, `viewH = aimViewH` |
| 1.30 | первая оставшаяся птица (сначала из ложа, потом по очереди справа налево) прыгает: вверх на 0.9 м за 0.18 с, вниз за 0.18 с. На пике — число «10000» её цвета, `addScore(10000)`, звук «динь» с тоном `+1 полутон` для каждой следующей |
| +0.45 на птицу | следующая птица |
| конец + 0.5 | птицы исчезают облачками или остаются (косметика). Затем окно результатов |

- Если птиц не осталось, сразу после баннера показываем результаты (0.6 с).
- Пропуск тапом: весь остаток бонуса начисляется мгновенно, анимация ускоряется ×4.

Окно результатов:
- выезд снизу 0.4 с (easeOutBack);
- счёт крутится от 0 до итога за 0.8 с;
- звёзды появляются по одной с интервалом 0.35 с: scale 0 → 1.3 → 1 за 0.25 с, искры, «дзынь» с растущим тоном. Незаработанные звёзды — серые силуэты `#6B6B6B` с альфой 0.5;
- «Новый рекорд!» — плашка с покачиванием ±4° на 1.2 Гц, если `score > best`;
- кнопки «Меню / Заново / Дальше» становятся активны через 0.3 с после последней звезды.

## 11. Звёзды

### 11.1 Правила

- [факт] 1–3 звезды по итоговому счёту. Пороги свои у каждого уровня, прохождение даёт минимум 1 звезду.
- Данные уровня: `"stars": [s1, s2, s3]`, где `s1 ≤ сумма очков за свиней` (гарантированная звезда за прохождение).
- `stars = !won ? 0 : 1 + (score ≥ s2) + (score ≥ s3)`.
- [факт, ориентир] Порог 3★ в Classic обычно требует оставить 1–2 птицы и сильно разрушить сооружение. Форумные значения: 3★ для 1-3 ≈ 52 690, для 1-7 > 75 000.

### 11.2 Первичная формула (при авторинге) [рекомендация]

```ts
// N — птиц в уровне; nMin — минимум птиц для прохождения по замыслу дизайнера
// P — очки за всех свиней с максимальным уроном; B — сумма максимумов по всем разрушаемым блокам
function autoStars(N, nMin, P, B): [number, number, number] {
  const r = (x: number) => Math.round(x / 1000) * 1000;
  const s1 = 0;
  const s2 = r(P + 0.35 * B + 10000 * Math.max(0, N - nMin - 1));
  const s3 = r(P + 0.55 * B + 10000 * (N - nMin));
  return [s1, s2, Math.max(s3, s2 + 5000)];
}
```

Пример. Три свиньи (малая, средняя, большая): P = 15 350. Блоки: 10 дерева 1×1 (по 702), 6 стекла (по 601), 4 камня (по 803) — B = 13 838. N = 3, nMin = 2. Получаем s2 = 20 000, s3 = 33 000.

### 11.3 Калибровка ботом (обязательна перед релизом уровня) [рекомендация]

- Headless-прогон на Node без рендера: planck детерминирован при одинаковом порядке создания тел и фиксированном dt.
- Перебор выстрелов: угол 0…80° с шагом 1°, натяжение 0.55…1.0 с шагом 0.05, способность — без неё и в момент 0.4/0.6/0.8 времени до расчётного удара. Жадный поиск: для каждой птицы лучший выстрел по приросту `score + 5000·killedPigs`, глубина — все птицы. Около 1500 симуляций на птицу при 10× ускорении — минуты на уровень.
- Итог: `s3 = r(0.9 · botBest)`, `s2 = r(0.7 · botBest)`. Если бот не проходит уровень за N птиц — уровень сломан.
- Результаты бота кладём в `levels/*.json` (`"starsSource": "bot@<git-sha>"`). Регрессионный тест: пересчёт не должен уводить пороги больше чем на 15%.

## 12. Рекорды, прогресс, рестарт

### 12.1 Хранение (`localStorage`, ключ `abclone:v1:progress`, всегда в try/catch)

```json
{
  "version": 1,
  "levels": {
    "1-1": { "cleared": true, "best": 41230, "stars": 3, "attempts": 4, "goldenEgg": false }
  },
  "settings": { "aimAssist": "off", "music": 0.6, "sfx": 0.9, "reducedShake": false },
  "lastLevel": "1-2"
}
```

- Запись — только при входе в `RESULTS(WON)`: `best = max(best, score)`, `stars = max(stars, newStars)`. `attempts++` — на каждый старт или рестарт.
- Если хранилище недоступно, игра работает в памяти без ошибок, прогресс живёт только в сессии.

### 12.2 Открытие уровней [рекомендация, как в Classic]

- Уровень `n+1` открывается прохождением `n` (хотя бы 1★).
- Новый эпизод требует прохождения последнего уровня предыдущего и `≥ 0.5 · 3 · levelsInEpisode` звёзд в нём. Бонус-уровни открываются звёздами или золотыми яйцами.
- Экран выбора уровня показывает 0–3 звезды и `best`.

### 12.3 Рестарт

- Где: кнопка ↻ в HUD (слева сверху рядом с паузой), клавиша `R`, кнопка в паузе, в экранах поражения и результатов.
- Без подтверждения: в Classic рестарт мгновенный, и это часть «петли попыток». Мгновенный рестарт — главный фактор удержания; подтверждение ломает ритм «ещё разок».
- Порядок:
  1. затемнение 0.15 с;
  2. `world` пересоздаётся из JSON уровня (не откат состояния);
  3. сбрасываются счёт, след, `userViewH`, таймеры;
  4. короткое интро (раздел 6.3, колонка «повтор»);
  5. проявление 0.2 с.

  Итого до `READY` ≈ 1.9 с.
- Бег по уровням: «Дальше» на экране результатов загружает следующий уровень с полным интро.

### 12.4 Пауза

- `Esc`, `P`, кнопка ‖ или потеря фокуса или видимости вкладки (авто-пауза). Аккумулятор fixed-step при снятии паузы обнуляется, чтобы не было «скачка».
- Меню паузы: «Продолжить / Заново / Уровни / Звук / Прицел».
- Таймеры автомата и анимации стоят. Музыка приглушается до 30%.

## 13. Конечный автомат уровня

### 13.1 Диаграмма

```
LOADING ──► INTRO_HOLD ──► INTRO_PAN ──► BIRD_TO_SLING ──► READY ◄───────────────────┐
              │ tap             │ tap                          │  pointerdown на птице │
              └──── skip(0.3s) ─┴──────────►BIRD_TO_SLING      ▼                       │
                                                            AIMING ── d<R_CANCEL ──────┤
                                                               │ release d≥R_CANCEL    │
                                                               ▼                       │
                                                            LAUNCH (1 тик)             │
                                                               ▼                       │
                                                            FLYING ── retire ─► LINGER ─► CAMERA_RETURN ─┬─ birds>0 ─► BIRD_TO_SLING
                                                                                                         └─ birds=0 ─► SETTLING
SETTLING ── settled|7s, pigs>0 ──► LOST_BANNER ──► RESULTS(LOST)
ANY_PLAY_STATE ── pigsAlive==0 ──► VICTORY_DELAY ──► CLEARED_BANNER ──► BONUS_COUNT ──► RESULTS(WON)
ANY (кроме LOADING/RESULTS) ── pause ──► PAUSED ── resume ──► (предыдущее)
ANY ── restart ──► LOADING
```

### 13.2 Таблица состояний

| Состояние | Вход (действия) | Ввод | Выход и переход | Длительность |
|---|---|---|---|---|
| `LOADING` | парсинг JSON, создание тел, прогрев кэша спрайтов, `pigsAlive = count` | — | готово → `INTRO_HOLD` | < 300 мс |
| `INTRO_HOLD` | камера в `focus` | tap → skip | таймер → `INTRO_PAN` | 1.0 с (повтор 0.3) |
| `INTRO_PAN` | твин камеры к aim view | tap → skip | конец твина → `BIRD_TO_SLING` | 1.8 с (повтор 0.8) |
| `BIRD_TO_SLING` | птица из очереди прыгает в ложе; очередь сдвигается вправо за 0.3 с | пан и зум | приземлилась → `READY` | 0.45 с |
| `READY` | idle-анимации: моргание каждые 2–5 с, подпрыгивание очереди каждые 1.5–4 с | захват, пан, зум, пауза | захват → `AIMING` | ∞ |
| `AIMING` | `sling:grab` | drag, release, колесо-зум | `d < R_CANCEL` → `READY` (пружина 0.25 с); иначе → `LAUNCH` | ∞ |
| `LAUNCH` | раздел 3.1 | — | → `FLYING` | 1 тик |
| `FLYING` | следование камеры, след | tap → способность; пан и пинч → override | `retire` → `LINGER` | ≤ 12 с |
| `LINGER` | облачко перьев | пан и зум | 0.6 с или calm → `CAMERA_RETURN` | ≤ 0.6 с |
| `CAMERA_RETURN` | твин к aim view (`userViewH`) | — | конец твина → `BIRD_TO_SLING` или `SETTLING` | 0.6–1.4 с |
| `SETTLING` | `t0 = now` | пан и зум | `settled` или 7 с → `LOST_BANNER` | ≤ 7 с |
| `VICTORY_DELAY` | `t0 = now`; если не `AIMING` — захват запрещён | пан и зум; доигрывание `AIMING` и `FLYING` | `t ≥ 1.2 && (settled \|\| t ≥ 3.5)` и нет летящей птицы (птица в полёте — ждём `retire`, до 6 с) → `CLEARED_BANNER` | 1.2–3.5 с |
| `CLEARED_BANNER` | `scoringLocked = true`, фанфара | tap → ускорить | 1.2 с → `BONUS_COUNT` | 1.2 с |
| `BONUS_COUNT` | раздел 10 | tap → мгновенно | все птицы посчитаны → `RESULTS(WON)` | 0.3 + 0.45·n с |
| `LOST_BANNER` | «УРОВЕНЬ НЕ ПРОЙДЕН», свинья смеётся, грустная музыка | — | 1.0 с → `RESULTS(LOST)` | 1.0 с |
| `RESULTS` | сохранение прогресса (только WON), окно | кнопки | действие пользователя | ∞ |
| `PAUSED` | стоп симуляции и таймеров | кнопки меню | resume → предыдущее | ∞ |

### 13.3 Каркас реализации

```ts
type LevelState =
  | 'LOADING' | 'INTRO_HOLD' | 'INTRO_PAN' | 'BIRD_TO_SLING' | 'READY' | 'AIMING' | 'LAUNCH'
  | 'FLYING' | 'LINGER' | 'CAMERA_RETURN' | 'SETTLING' | 'VICTORY_DELAY' | 'CLEARED_BANNER'
  | 'BONUS_COUNT' | 'LOST_BANNER' | 'RESULTS' | 'PAUSED';

const PLAY_STATES = new Set<LevelState>(['READY','AIMING','LAUNCH','FLYING','LINGER','CAMERA_RETURN','BIRD_TO_SLING','SETTLING']);

class LevelFSM {
  state: LevelState = 'LOADING'; t = 0; prev?: LevelState;
  go(s: LevelState) { this.exit(this.state); this.state = s; this.t = 0; this.enter(s); bus.emit('state', s); }
  fixedUpdate(dt: number) {                     // вызывается из аккумулятора 1/60
    if (this.state === 'PAUSED') return;
    this.t += dt;
    physics.step(dt);                            // мир живёт во всех состояниях кроме PAUSED/LOADING
    if (PLAY_STATES.has(this.state) && level.pigsAlive === 0) return this.go('VICTORY_DELAY');
    switch (this.state) {
      case 'FLYING':        if (bird.shouldRetire()) { bird.retire(); this.go('LINGER'); } break;
      case 'LINGER':        if (this.t >= 0.6 || settle.calm) this.go('CAMERA_RETURN'); break;
      case 'CAMERA_RETURN': if (cam.tweenDone) this.go(level.birdsRemaining > 0 ? 'BIRD_TO_SLING' : 'SETTLING'); break;
      case 'SETTLING':      if (settle.settled(0.6) || this.t >= 7) this.go('LOST_BANNER'); break;
      case 'VICTORY_DELAY': {
        const birdBusy = bird.active && !bird.retired;
        if (birdBusy && bird.shouldRetire()) bird.retire();
        if (!birdBusy && this.t >= 1.2 && (settle.settled(0.4) || this.t >= 3.5)) this.go('CLEARED_BANNER');
        break;
      }
      // ... остальные состояния — по таймерам из таблицы 13.2
    }
  }
}
```

Шаг физики:
- аккумулятор, `MAX_STEPS_PER_FRAME = 5`;
- остаток времени теряется, если кадр дольше 83 мс (вкладка тормозит);
- интерполяция рендера по `alpha = acc/dt` между прошлым и текущим состоянием тел.

## 15. Что переносить из Angry Birds 2 (2015–2020)

- уровни из нескольких комнат; запас птиц между комнатами не пополняется;
- карты птиц: игрок сам выбирает следующую;
- Destructometer заполняется от разрушений и даёт дополнительную карту (птицу, редко заклинание); каждое следующее заполнение требует больше; золотая свинья заполняет шкалу мгновенно;

- 5 жизней; самоцветы;
- боссы;
- бонусы «Strike!» +25 000 (комната одной птицей) и «Birdie!» +10 000 (двумя).

## 17. Согласование с другими документами и открытые вопросы

1. **G и V_MAX** (02-physics). При другом g пересчитать `V_MAX`, `CHUCK_BOOST`, скорость яйца Matilda с коэффициентом `sqrt(g/12.5)`. Тайминги (`RETIRE_*`, `CALM_*`) не меняются.
2. **HP блоков и свиней** (02-physics). Очки за урон считаются как доля снятого HP, поэтому шкала HP на них не влияет.
3. **Размер блока 1×1 = 0.85 м** (04-levels). Если блок другой, `PTS_DMG_PER_M2` пересчитать так, чтобы блок 1×1 давал 100/200/300.
4. **Параметры способностей** (03-birds). Здесь — только окна активации и порядок событий.
5. **Мёртвые зоны рогатки** на маленьких экранах: если `R_MAX · ppm < 90 css px`, точность прицеливания падает. Минимум `viewH` тогда ограничить так, чтобы `R_MAX ≥ 90 px`.
